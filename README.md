# 다교연 클로드 코드 튜터 (gea-claude-tutor)

**AI가 처음인 기독교 교육단체 실무자를 위한 10회차 자가학습 튜터**입니다.
Claude 데스크탑 앱의 **Code** 탭에서 이 폴더를 열고 "1회차 시작"이라고 말하면, AI 튜터가 한 단계씩 친절하게 안내합니다.

> 클로드 코드는 내 컴퓨터 폴더 안에서 직접 일하는 **슈퍼 스마트한 신입 동료**입니다.
> 이 과정은 그 동료에게 일을 맡기고, 확인하고, 반복 업무를 자산으로 만드는 법을 익히는 여정입니다.

다음세대교육연합(다교연)과 소속 단체(다니엘칼리지, 교과서진화론개정추진회, 미션펀드, SHINE행복한학교, 엘리온에듀학원) 실무자들이 강의 전에 보내 주신 사전질문을 바탕으로 만들었습니다.

---

## 🚀 시작하기

**준비물**: Claude 데스크탑 앱(유료 요금제 — Pro 또는 단체 Team), Git, (Windows) Python, GitHub 계정

### 1. 이 폴더 받기 (둘 중 하나)

**방법 A — 내려받기(가장 쉬움)**
1. 이 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP**
2. 받은 ZIP 파일의 압축을 풀고, 폴더를 **문서** 폴더로 옮깁니다. (폴더 이름이 `gea-claude-tutor-main`이어도 그대로 쓰면 됩니다.)

**방법 B — Claude에게 부탁하기(딸깍)**
1. Claude 데스크탑 앱 → **Code** 탭 → **Local** → **Select folder**로 **문서** 폴더를 엽니다.
2. 이렇게 입력합니다.
   ```
   https://github.com/ByungtaeAhn-cs/gea-claude-tutor 를 이 폴더에 받아줘
   ```
3. Claude가 명령 실행 승인을 요청하면 허용합니다.

### 2. 튜터 시작하기
1. Code 탭에서 **Select folder**로 `gea-claude-tutor` 폴더를 엽니다.
2. 입력창에 이렇게 입력합니다.
   ```
   1회차 시작
   ```
3. 다음에 이어서 할 때는 같은 폴더를 열고 `이어서 하자`라고 말하면 됩니다.

사용법 자세히 보기: [자율학습_가이드.md](자율학습_가이드.md)

## 📚 10회차 구성

| Phase | 회차 | 주제 | 이런 걸 할 수 있게 됩니다 |
|-------|------|------|---------------------------|
| 1. 동료 맞이하기 | 01 | 첫 출근 — 설치 확인과 첫 대화 | 내 폴더의 파일을 AI가 직접 정리하게 하기 |
| | 02 | 일 잘 시키는 법 — 위임 브리핑과 딸깍 프롬프트 | "먼저 조사하고 나를 인터뷰해줘"로 완성도 높이기 |
| 2. 호흡 맞추기 | 03 | 동료의 책상과 기억 — 세션과 컨텍스트 관리 | 대화가 길어져도 헤매지 않게 일하기 |
| | 04 | 세이브 포인트와 자료실 — Git과 파일 관리 | "최종_진짜최종" 없이 최신본 관리하기 |
| 3. 실무 맡기기 | 05 | 문서에서 정보 뽑기와 개인정보 지키기 | 신청서 → 엑셀 표, 교과서 PDF 분석 |
| | 06 | 숫자는 코드로 — 엑셀 업무 자동 점검 | 후원 엑셀 성공·실패·신규 자동 점검 |
| | 07 | 원소스 멀티유즈 — 콘텐츠 한 번에 만들기 | 원고 하나로 PPT·활동지·소식지·SNS 글 |
| 4. 반복을 자산으로 | 08 | 도구 상자 넓히기 — 에이전트·스킬·플러그인 | 검증된 도구 찾아 안전하게 설치하기 |
| | 09 | 한 바퀴 돌린 일을 스킬로 | 반복 업무를 나만의 명령으로 만들기 |
| | 10 | 할루시네이션 없는 위임 — 에이전틱 워크플로우 | 믿을 수 있게 맡기고, 예약해서 자동 실행하기 |

- **회차당**: 본 학습 60~90분 + 실전 과제(단체별 선택, 여러 번 나눠서)
- **관통 프로젝트**: 2회차에 내 단체의 실제 과제 하나를 골라 10회차까지 키워 완성합니다.

## 🗂️ 폴더 구조

```
gea-claude-tutor/
├── 회차별자료/        01~10회차 교재
├── 실습자료/          실습용 가상 샘플 (개인정보 없음)
├── 실습공간/          실제로 실습하는 곳 (내 컴퓨터에만 남음)
├── 내_학습기록/       튜터가 저장하는 내 진도·프로필·프로젝트 (내 컴퓨터에만 남음)
├── 자율학습_가이드.md  사용 설명서
├── .claude/           튜터 스킬·출력 스타일·검수자 에이전트
└── plugins/gea-toolkit/  어느 폴더에서나 쓰는 '딸깍' 도구 모음 (8회차에서 설치)
```

## 🧰 gea-toolkit 플러그인 (8회차)

이 저장소는 플러그인 마켓플레이스이기도 합니다. `gea-toolkit`을 설치하면 **어느 폴더에서나** 아래 도구를 쓸 수 있습니다.

| 명령 | 하는 일 |
|------|---------|
| `/gea-toolkit:handoff` | 지금까지 한 일을 인수인계 메모로 저장 → 새 세션에서 이어하기 |
| `/gea-toolkit:research-first` | 바로 만들지 않고 먼저 조사하고, 나를 인터뷰한 뒤 계획을 보여 줌 |
| `/gea-toolkit:eli5` | 지금 하는 일을 초등학생도 알게 설명 |
| `/gea-toolkit:self-review` | 결과물을 스스로 검토하고 확실/불확실/추측 표시 |

설치 방법은 8회차에서 튜터가 안내합니다.
