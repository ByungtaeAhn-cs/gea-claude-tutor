# blog-image — 찾기 · 라이선스 · 출처대장 · (선택) AI 삽화 · 미리보기 · 패키지

대상: $ARGUMENTS

## 원칙
- **라이선스를 모르면 쓰지 않습니다.** 받은·만든 이미지는 한 장도 빠짐없이 `출처대장.csv`에 남깁니다.
- 단체 블로그는 후원(기부) 링크가 있으므로 **상업 이용으로 보고** 보수적으로 고릅니다.
- 사진 속 사람의 얼굴은 **동의가 먼저**입니다(아래 '사람 사진 규칙').

## 작업 이력
이미지·미리보기·패키지는 각각 한 단계입니다.
```
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 이미지 --상태 완료 --산출물 출처대장.csv 배치_<주제>.json
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 미리보기 --상태 완료 --산출물 배치_<주제>_미리보기.html
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 패키지 --상태 완료 --산출물 발행/패키지_<주제>.json
```
실패하면 `--상태 실패 --오류 "…"`로 남기고 멈춥니다. 다시 할 때는 이미 받은 이미지·대장을 다시 받지 않습니다.

## 라이선스 기준표
| 라이선스 | 기본 | 리터칭(삽화풍 변환·자르기) | 표기 |
|---|---|---|---|
| CC0 · 퍼블릭 도메인(PDM·PD) | 허용 | 가능 | 의무 없음(권장: 제목·작가·출처) |
| CC BY | 허용 | 가능 | **필수**: 제목·작가·출처·라이선스(링크), 바꿨으면 바꾼 사실 |
| Pexels · Pixabay | 허용 | 가능 | 권장("Photo by … on Pexels" 등) |
| 공공누리 제1유형 | 허용 | 가능 | 필수(공공누리 공식 문구) |
| CC BY-SA | `--넓게`일 때만 | ⚠️ 리터칭한 결과물도 **CC BY-SA로 공개·표기** | 필수 |
| CC BY-ND · 공공누리 제3유형 | `--넓게`일 때만 | **금지**(자르기 포함) | 필수 |
| NC가 붙은 것 · 공공누리 제2·4유형 | **제외** | — | — |
| GFDL만 · 라이선스 불명 | **제외** | — | — |
- **Unsplash는 API로 받지 않습니다**(핫링크 의무가 네이버 업로드와 충돌). 꼭 필요하면 사람이 웹에서 직접 받고 대장에 손으로 적습니다.
- 옛 그림의 **복제 사진**은 한국법상 사진가 권리가 불확실 → 출처가 PD·CC0을 **분명히 표시한 것만**.
- 받기 전에 **원본 페이지에서 라이선스를 한 번 더 확인**합니다.

## 단계

### 1. 사진 자리 목록
- 배치 JSON에서 `"자리"`가 있는 블록을 표로 보여 줍니다(블록 번호 · 무엇을 보여 줄지 · 캡션 초안).
- 자리마다 묻습니다: **단체가 가진 사진이 있나요?** → 있으면 그 사진(사람 사진 규칙 확인) / 없으면 무료 이미지 / (선택) AI 삽화.

### 2. 무료 이미지 찾기
```
python "<스킬 기본 폴더>/scripts/무료사진찾기.py" 검색 --검색어 "Haeckel embryos Anthropogenie" --곳 wikimedia,openverse --출력 "<글 폴더>/이미지후보_1.json"
```
- 영어 검색어 1~3개. Pexels·Pixabay는 환경변수 `PEXELS_API_KEY`·`PIXABAY_API_KEY`가 있을 때만(키는 프로젝트 폴더에 저장하지 않음).
- 결과: `이미지후보_1.json`(받기용)과 `이미지후보_1.md`(썸네일 표).
- 위키미디어는 폭 1280px 썸네일(표준 폭)로 받습니다. 서버가 60초 넘게 기다리라고 하면 멈추고 연락처(`BLOG_CONTACT_EMAIL`) 설정을 안내합니다.

### 3. 고르기
- 2~3개로 좁혀 미리보기 이미지를 **직접 보고** 판단: 자리 설명과 맞는가, 내용이 정확한가(원본인지 후대 재수록본인지), 글자가 읽히는가.
- 고른 후보의 **원본 페이지**를 열어 라이선스·작가·제한 표시(초상권·상표)를 다시 확인 → 사람에게 "이 이미지로 할까요?"

### 4. 받기 → 출처대장
```
python "<스킬 기본 폴더>/scripts/무료사진찾기.py" 받기 --후보 "<글 폴더>/이미지후보_1.json" --번호 5 --폴더 "<글 폴더>/이미지" --대장 "<글 폴더>/출처대장.csv"
```
- 파일 이름은 영문·숫자로 자동(예: `01_wikimediac_haeckel_anthropogenie_1874.jpg`).
- `출처대장.csv` 열: 파일 · 서비스 · 제목 · 원본URL · 이미지URL · 작가 · 작가URL · 라이선스 · 라이선스URL · 표기문구 · **변경사항** · 리터칭 · 주의 · 받은날짜
- **표기문구 다듬기**: 자동 문구는 거칠 수 있으니 원본 페이지를 보고 독자가 읽기 좋은 한국어로 고칩니다. 예: `에른스트 헤켈, 『인류발생학(Anthropogenie)』(1874) 도판 IV–V / 위키미디어 공용 / 퍼블릭 도메인`. 퍼블릭 도메인 표시(PDM)면 라이선스URL에 `https://creativecommons.org/publicdomain/mark/1.0/`.
- 자르기·밝기 조절·삽화 변환을 하면 **변경사항** 칸을 고칩니다.

### 5. (선택) 소제목마다 AI 삽화 만들기
사진으로 보여 주기 어려운 내용(개념도, 장면 묘사)을 소제목마다 새 삽화로 만듭니다.
- **경로**: 공용 도구 `AI삽화.py`(다른 개발자가 만드는 중 — 명령 형식은 그 파일 머리말을 따릅니다. **연결 확인 필요**). 이 도구는 **Codex CLI**를 ChatGPT 계정으로 로그인해 둔 상태에서 `$imagegen`으로 그림을 만듭니다(**ChatGPT Plus 이상 필요**, API 키 과금 방식이 아님). 결과는 `~/.codex/generated_images/<세션>/`에 생기고, 도구가 글 폴더 `이미지/`로 복사합니다(Windows에서는 다른 폴더로 바로 저장이 안 되는 것이 확인됨).
- Plus가 없으면 이 단계를 건너뛰고 무료 이미지로 갑니다.
- **만들기 전에 사람에게 보여 줄 것**: 소제목별 삽화 설명(무엇을 그릴지), 비율, 스타일. 비율은 블로그 본문에 맞게 고릅니다: 소제목 대표 삽화 `16:9`, 정사각 `1:1`, 세로형 `3:4`.
- **금지**: 실사처럼 보이는 가짜 사진(실제 사건·장소·사람을 찍은 것처럼 보이는 그림), **실존 인물**(역사 인물 초상 포함)을 그리게 하기, 실제 교과서·로고·상표 흉내.
- 만든 뒤: 캡션에 **"AI로 만든 삽화"** 표기, 출처대장에 한 줄(서비스: ChatGPT 이미지(Codex), 라이선스: 'OpenAI 약관상 이용자 소유', 변경사항: `AI 생성`), 배치 JSON 맨 위 `"AI활용표시": true`(임시저장 뒤 사람이 그 삽화를 눌러 사진 위 'AI 활용 설정'을 켬 — 확장은 '주의'로 알려 줌).

### 6. (선택) 사진을 삽화풍으로 리터칭
- **같은 경로**(`AI삽화.py`, Codex CLI 구독 로그인)로 사진을 넣어 변환합니다. 이미 구독 중인 서비스를 쓰고, 없으면 ChatGPT(GPT 이미지)를 권합니다. Plus가 없으면 리터칭하지 않고 원래 사진(또는 무료 이미지)을 씁니다.
- Claude는 이미지를 직접 만들거나 고치지 못합니다. Claude는 원본 고르기·라이선스 확인·대장 기록·배치 반영을 맡습니다.
- **법적 필수 규칙(바꾸지 않음)**
  1. **얼굴을 알아볼 수 있는 사진은 동의를 확인하기 전에는 외부 AI에 올리지 않습니다.** 만 14세 미만은 **법정대리인(보호자) 동의**. 삽화로 바꿔도 알아볼 수 있으면 초상권 문제는 그대로입니다(대법원 2004다16280 판결이 '그림묘사'를 명시).
  2. **변환 사실을 표기**: 캡션 "AI로 삽화풍 변환한 이미지", 출처대장 변경사항 `AI 변환(서비스 이름)`, 배치 `"AI활용표시": true`.
  3. **출처 정보를 지우지 않습니다**: AI가 넣은 C2PA·워터마크를 제거·숨기지 않습니다(`발행패키지.py`도 변경사항에 'AI'가 있는 이미지는 메타데이터를 건드리지 않음).
  4. 라이선스가 리터칭을 허용하는지 먼저(ND·공공누리 3유형 금지, BY-SA는 결과물도 BY-SA).

### 7. 배치 JSON 채우기
- `"자리"`를 지우고 `"사진": ["이미지/01_….jpg"]`(배치 파일 기준 상대경로), 캡션(`설명`)에 그림이 무엇인지 + 짧은 출처.
- 글 끝 사진 출처 문구: `python "<스킬 기본 폴더>/scripts/무료사진찾기.py" 표기 --대장 "<글 폴더>/출처대장.csv"` → 글 끝 **하나뿐인** `참고자료` 블록의 `목록` 끝에 `사진 출처: …` 줄로 덧붙입니다(블로그 도우미 확장은 참고자료 블록마다 '참고자료'라는 머리글을 붙이므로 블록을 따로 만들지 않음). **원고 md에도 같은 내용을 반영**합니다.

### 8. 미리보기
```
python "<도구>/미리보기.py" "<글 폴더>/배치_<주제>.json" --열기
```
- `--열기`: 기본 브라우저로 엽니다. PC/모바일(375px)을 바꿔 보며 담당자와 확인하고, 오른쪽 '작성자용 점검'(사진 자리·누수·태그 수·AI 활용·승인 상태)을 봅니다.
- Code 탭 Browser 창에서 보려면 `--이미지 내장`(그 창은 내 PC 파일을 정적 스냅숏으로 열어 상대경로 그림이 안 보이고, 약 500KB가 넘는 파일은 열지 못함 — 1차 리허설 관찰).
- **승인**: 담당자가 "이 글 승인"이라고 하면 배치의 `승인`을 `{"상태":"승인됨","승인자":"<직책>","시각":"<지금>"}`으로 바꿉니다(사람의 말이 있을 때만).

### 9. 발행 패키지 (팩트체크·다듬기가 끝난 뒤)
```
python "<스킬 기본 폴더>/scripts/발행패키지.py" "<글 폴더>/배치_<주제>.json" --대장 "<글 폴더>/출처대장.csv"
```
- **누수 점검**: 글에 `[S3]` 같은 카드 번호, `[담당자 확인`, '내부용', '발행 금지', '예상 반론'이 남아 있으면 **패키지를 만들지 않고** 멈춥니다.
- 사진 자리가 남았거나 태그·그룹·장소 수가 넘치거나 10MB 넘는 파일이 있어도 멈춥니다.
- **Pillow 필수**(표준 라이브러리만으로는 위치 정보를 다 지울 수 없어 예외로 씀): 없으면 패키지를 만들지 않고 멈춥니다. 그때는 사람에게 "Pillow를 이 프로젝트 가상환경에 설치할까요?"라고 묻고, 승인을 받은 뒤 설치합니다(Windows `.venv\Scripts\pip install pillow` / Mac `.venv/bin/pip install pillow`).
- 업로드 사본: 영문 파일명(`02_01.jpg`). 모든 사진을 Pillow로 **다시 저장**해 방향을 그림에 반영하고 EXIF·GPS·기기 정보·XMP·IPTC·모션포토 꼬리(JPEG 뒤에 붙은 영상)·PNG/WebP 메타를 버립니다(색 프로필만 남김). 다시 열어 남은 것이 있으면 멈춥니다. AI로 만든·바꾼 이미지는 출처 정보(C2PA)를 지우지 않도록 그대로 복사하되, GPS·기기 정보가 있으면 멈춥니다.
- 묶음 번호·최종 점검은 공용 `발행서버.py`의 `build_bundles()`가 합니다(못 찾으면 `--공용 <폴더>`로 위치 지정).
- 결과 `발행/패키지_<주제>.json` + `발행/사진묶음_<주제>/` → **naver-draft** 스킬로.

## 사람 사진 규칙
- 단체 행사 사진: `사진동의대장`(CLAUDE.md에 위치)에서 게시 동의를 확인합니다. 확인 안 되면 뒷모습·손·원경처럼 알아볼 수 없는 사진만.
- 스톡 사진 속 인물: 부정적 맥락, 단체를 보증하는 것처럼 보이는 사용을 피합니다.
- 사진 속 사람의 이름·관계를 추측해서 캡션에 쓰지 않습니다.

## 스스로 점검
- [ ] 사진 자리가 모두 채워졌다(또는 사람이 '사진 없이'로 정했다)
- [ ] 받은·만든 이미지가 모두 출처대장에 있고, 라이선스URL·표기문구가 있다
- [ ] NC·불명 라이선스가 없다. ND·공공누리 3유형은 변경하지 않았다
- [ ] AI 이미지는 캡션 표기·대장 'AI 생성/변환'·`AI활용표시: true`
- [ ] 얼굴이 보이는 사진은 동의를 확인했다(14세 미만은 보호자)
- [ ] 패키지 누수 점검을 통과했다

## 하지 않는 것
- 라이선스를 확인하지 않고 받기, 검색 결과 이미지를 핫링크로 걸기, Unsplash API 사용
- 실사 같은 가짜 사진·실존 인물 그림 만들기, 워터마크·C2PA 지우기
- 동의 확인 전 얼굴 사진을 외부 AI에 올리기
- 출처대장 없이 이미지 쓰기

## 예시 — 출처대장 한 줄(AI 삽화)
