# blog-research — 자료조사 → 출처 카드

주제(와 카테고리): $ARGUMENTS

좋은 블로그 글은 **근거를 먼저 모으고** 씁니다. 이 스킬은 글감이 될 자료를 믿을 만한 순서로 찾아, 작가·팩트체크 단계가 그대로 쓸 수 있는 **출처 카드**로 정리합니다. 글은 아직 쓰지 않습니다.

## 먼저 읽을 것
1. 프로젝트 `CLAUDE.md` — 독자, 신학 테두리, 출처 표기, 단체 자료 폴더 위치, 도구 위치
2. `주제판.md`의 **카테고리 설정** — 이 카테고리의 발행 목적, 검색 키워드, 선호 출처, 최신성 수준, **검증 수준**
3. 이 스킬 폴더의 `scripts/`(스킬이 불리면 보이는 '기본 폴더' 아래): `학술검색.py`, `문서읽기.py`

## 검증 수준에 따라 깊이 바꾸기
| 검증 수준 | 언제(예) | 자료조사 깊이 |
|---|---|---|
| **엄격** | 교진추 자료실·칼럼·교과서 청원 자료처럼 과학·인용·논쟁이 들어간 글 | 단체 자료 → 1차 문헌까지 모두. 학술 API 검색어 2~3개, 상류 출처 거슬러 오르기 필수, 사실 하나에 1차 출처 카드 1장 이상. 카드에 쪽수·원문 문장. 반대 견해의 대표 문헌도 1~2장(예상 반론 메모용) |
| **보통** | 뉴스레터 블로그판, 교육 정책 소개 | 공식 기관 자료(보도자료·공문·법령) 우선, 숫자·날짜·인용마다 공식 출처 1개. 학술 검색은 필요할 때만 |
| **가벼움** | 행사 후기, 단체 소식, 추천 영상 | 단체 내부 기록(행사 일정·참석 인원·사진 동의 대장)과 대조. 외부 검색은 장소·인명 표기 확인 정도 |
- 최신성 수준(카테고리 설정)이 '최근 2년'이면 그보다 오래된 자료는 '배경'으로만 씁니다. '고전 문헌 허용'(예: 1874년 원전)이면 원전과 최신 연구를 함께 카드로 만듭니다.
- 카테고리 설정이 없으면 담당자에게 검증 수준을 한 번 묻고, 답이 없으면 **엄격**으로 합니다.

## 작업 이력
```
python "<도구>/작업이력.py" 시작 --폴더 "<글 폴더>" --편ID <편ID>          (새 글일 때 한 번)
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 자료조사 --상태 진행중
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 자료조사 --상태 완료 --산출물 자료조사_<주제>.md
```
API 오류·한도 초과로 멈추면 `--상태 실패 --오류 "…"`. 다시 할 때 이미 만든 후보 파일(`학술후보_*.md`)은 다시 검색하지 않고 씁니다.

## 단계

### 1. 글이 답할 질문 정하기
- 주제를 독자가 궁금해할 **질문 3~5개**로 나누고 "이 방향이 맞을까요?"라고 한 번 확인합니다(답이 분명하면 바로 진행).

### 2. 단체 자료 폴더 먼저
- `CLAUDE.md`의 단체 자료 폴더(예: `자료/`)에서 주제어(한글·영어)로 찾습니다: 소식지, 청원서, 강의안, 지난 글.
- 단체가 이미 밝힌 **입장·숫자·날짜**는 여기서 가져오고 카드에 파일 이름과 쪽을 적습니다. 단체 자료가 다른 문헌을 인용했으면 카드 '메모'에 "1차 문헌 확인 필요"로 남깁니다(5단계에서 추적).

### 3. 공식 기관·1차 자료 (PDF·HWP·HWPX 읽기)
- 정부·교육청·교육과정 기관·법령·학회·박물관·도서관의 **1차 출처**를 찾습니다. 뉴스·블로그·위키는 1차 출처를 찾아가는 **길잡이**로만.
- 공문·보도자료·법령 첨부 파일은 `문서읽기.py`로 필요한 부분만 꺼냅니다:
  ```
  python "<스킬 기본 폴더>/scripts/문서읽기.py" "<파일 경로 또는 내려받기 주소>" --찾기 고교학점제 진로 --앞뒤 1
  python "<스킬 기본 폴더>/scripts/문서읽기.py" 자료/교육과정.pdf --쪽 3-10 --찾기 진화
  ```
  - **저장하지 않음**: 주소를 주면 임시 폴더에 받았다가 읽은 뒤 바로 지웁니다. 필요한 문장만 출처 카드에 옮기고(쪽·구역 표시), 문서 전체를 프로젝트에 복사해 두지 않습니다.
  - **크기 제한**: 기본 30MB·400쪽. 큰 문서는 `--쪽`으로 범위를 좁힙니다.
  - **준비물**: HWPX는 설치 없이 됩니다. HWP는 `olefile`, PDF는 `pypdf`가 필요합니다(둘 다 BSD 라이선스, 순수 파이썬). 설치는 프로젝트 가상환경에: `python -m venv .venv` → Windows `.venv\Scripts\pip install olefile pypdf` / Mac `.venv/bin/pip install olefile pypdf` → 실행도 `.venv` 파이썬으로. 설치가 안 되면 PDF는 Claude Code의 Read 도구로 직접 읽고(한 번에 20쪽), HWP는 한글에서 HWPX·PDF로 저장해 읽습니다.
  - **스캔본 PDF**(글자가 안 나옴): Read 도구로 쪽 그림을 보고 필요한 문장만 옮겨 적습니다(OCR). 쪽이 많으면 기관에 텍스트본(HWP·HWPX)을 요청합니다. 옮겨 적은 문장은 카드에 "스캔본에서 옮김 — 대조 필요"로 표시합니다.
  - **배포용(암호) HWP**는 읽을 수 없습니다 → 같은 자료의 PDF를 찾습니다.

### 4. 학술 API
```
python "<스킬 기본 폴더>/scripts/학술검색.py" --검색어 "Haeckel embryo drawings" --개수 8 --출력 "<글 폴더>/학술후보_1.md"
python "<스킬 기본 폴더>/scripts/학술검색.py" --doi 10.1007/s004290050082 --출력 "<글 폴더>/학술후보_DOI.md"
```
- 영어 검색어 2~3개(카테고리 설정의 검색 키워드 참고). 결과는 **후보**일 뿐이니 글에 쓸 것만 고릅니다.
- 고르는 기준: 주제와 직접 관련, 1차 연구(뉴스·서한·서평이면 그렇다고 표시), 철회 표시 없음.
- 의생명 주제는 Europe PMC(스크립트는 제목·초록에서만 찾음), DOI 없는 인용 찾기는 Semantic Scholar 제목 검색, 국내 논문은 KCI.
- **구글 스칼라는 자동으로 조회하지 않습니다**(공식 API 없음, 약관·robots.txt가 자동 수집을 막음). 사람이 브라우저에서 보조로 확인하는 것은 괜찮습니다.
- 연락처 이메일: 환경변수 `BLOG_CONTACT_EMAIL`이 없으면 단체 공용 주소를 쓸지 한 번 묻고, 원하지 않으면 비운 채 진행합니다(조금 느림). 서버가 60초 넘게 기다리라고 하면 스크립트가 멈추고 알려 줍니다.

### 5. 상류 출처 거슬러 오르기
- 책·청원서·블로그가 인용한 문장은 **그 책이 인용한 1차 문헌**까지 찾아갑니다.
- 창조과학 학술지(Answers Research Journal, Journal of Creation, CRSQ, Origin Research Journal 등)는 대부분 **DOI가 없습니다**. 학술지 누리집에서 원문을 찾아 이름·저자·연도·권호를 정확히 적고, '동료심사를 거친' 같은 수식어는 **확인한 경우에만** 씁니다.

### 6. 출처 카드 쓰기
카드 하나 = 출처 하나. 번호는 [S1], [S2] … (작가·팩트체크가 이 번호로 부름)

| 항목 | 쓰는 법 |
|---|---|
| 제목 | 원문 제목 그대로(번역은 괄호) |
| 저자 | 성, 이름 순. 여러 명이면 첫 저자 + 외 |
| 연도 | 출판 연도(온라인 선공개와 다르면 둘 다) |
| 실린 곳 | 학술지 권(호): 쪽 / 출판사 / 기관 |
| URL·DOI | DOI가 있으면 `https://doi.org/…` |
| 글 종류 | 연구 논문 / 리뷰 / 뉴스 기사 / 독자 서한 / 서평 / 단행본 / 대중서 / 단체 게시물 / 공문·보도자료 / 법령 / 옛 문헌(원본) |
| 핵심 문장 | 원문에서 **그대로 옮긴** 짧은 문장(언어 그대로) + 우리말 뜻(따옴표 없이). 줄였으면 "…" |
| 쪽수 | 핵심 문장이 있는 쪽·구역(모르면 "확인 필요") |
| 확실/불확실 | **확실**: 원문이나 공식 서지에서 직접 확인 / **불확실**: 초록·2차 자료·자동 발췌·스캔본 옮겨 적기 / **확인 못 함** |
| 확인 범위 | 초록만 / 본문 / 도판 실물 / 서지만 |
| 쓸 곳 | 글의 어느 질문을 뒷받침하는지 |

### 7. 빈칸 정리
- 못 찾은 것, 사람에게 받아야 할 것(단체 내부 자료, 교과서 실물 쪽수, 유료 논문 PDF)을 목록으로 남깁니다.

## 보강 조사 (팩트체크·검수에서 '근거 부족'으로 걸렸을 때)
- **걸린 주장 하나만** 조사합니다. 자료조사 전체를 다시 하지 않습니다.
- 새 카드는 기존 번호 뒤에 붙이고(예: [S14]), 카드 '메모'에 "보강: C9 때문"처럼 이유를 적습니다.
- 끝까지 근거를 못 찾으면 "보강 실패 — 그 문장은 빼거나 수위를 낮출 것"으로 작가에게 넘깁니다.

## 출력: `자료조사_<주제>.md`
```markdown
# 자료조사: <주제>
- 조사일 · 카테고리(정확한 이름) · 검증 수준 · 최신성 · 독자
- 글이 답할 질문: 1) … 2) … 3) …
## 조사 경로 기록 (단체 자료 → 공식 기관 → 학술 API, 무엇을 어디서)
## 출처 카드
### [S1] <제목>
| 항목 | 내용 |
## 글감 메모 (사실 / 해석 — 해석은 판정하지 않고 팩트체크의 예상 반론 메모로)
## 확인 못 한 것 · 사람에게 받을 것
```
끝나면 "다음은 blog-writer로 초안을 쓸 차례입니다"라고 안내합니다.

## 스스로 점검
- [ ] 검증 수준에 맞는 깊이로 찾았다(엄격이면 모든 사실에 1차 출처 카드)
- [ ] 모든 카드에 URL·DOI(옛 문헌은 소장처·디지털 사본 주소)와 '확인 범위'가 있다
- [ ] 핵심 문장은 원문 그대로이고, 원문을 못 본 것은 '불확실'
- [ ] 뉴스·서한·서평·대중서를 연구 논문처럼 적지 않았다
- [ ] 공문·PDF 전체를 프로젝트에 저장하지 않았다(필요한 문장만 카드로)
- [ ] 해석 논쟁은 판정하지 않았다

## 하지 않는 것
- 출처를 지어내거나, 원문을 보지 않고 '확실'로 표시하기
- 의역한 문장에 따옴표를 붙여 원문처럼 만들기
- 구글 스칼라 자동 조회, 유료 논문 우회 다운로드, 배포용 HWP 암호 풀기
- 단체 내부 자료·개인정보·보안국가 선교 정보를 외부 검색어에 넣기
- 진화론·창조론의 해석 논쟁을 판정하기

## 예시 카드
### [S2] There is no highly conserved embryonic stage in the vertebrates: implications for current theories of evolution and development
| 항목 | 내용 |
|---|---|
| 저자 | Richardson, M. K. 외 6명 |
| 연도 | 1997 |
| 실린 곳 | *Anatomy and Embryology* 196(2): 91–106 |
| DOI | https://doi.org/10.1007/s004290050082 |
| 글 종류 | 연구 논문(리뷰 성격 포함) |
| 핵심 문장 | "Our survey seriously undermines the credibility of Haeckel's drawings, which depict not a conserved stage for vertebrates, but a stylised amniote embryo." (우리 조사는 헤켈 그림의 신뢰성을 심각하게 훼손한다는 뜻) |
| 쪽수 | 초록 |
| 확실/불확실 | 서지·초록 문장: 확실(Crossref·Europe PMC) |
| 확인 범위 | 초록만(본문 유료·미확보) |
| 쓸 곳 | 질문 2 "무엇이 문제로 지적됐나" |
