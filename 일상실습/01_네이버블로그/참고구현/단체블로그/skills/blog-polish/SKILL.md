# blog-polish — 문장 다듬기 (뜻은 그대로)

대상 원고: $ARGUMENTS

팩트체크를 통과한 원고의 **말투만** 다듬습니다. 사실은 이미 확인됐으므로 이 단계에서 사실이 바뀌면 안 됩니다. 그래서 ① 바꾸면 안 되는 문장을 먼저 묶어 두고 ② 나머지만 다듬고 ③ 기계로 대조해 위험한 변화는 되돌린 뒤 ④ 남은 변화는 뜻을 직접 비교합니다.

> 참고 출처: 이 스킬은 공개 스킬을 복사하지 않고 직접 썼습니다. GitHub 등의 공개 '문장 다듬기' 스킬을 참고하거나 가져올 때는 그 저장소의 라이선스(예: MIT, CC BY-SA)와 출처 표기 조건을 먼저 확인하고, 이 파일 머리에 출처를 적습니다.

## 먼저 읽을 것
- 프로젝트 `CLAUDE.md`의 톤 규칙, `기준예시/`의 글(우리 단체의 자연스러운 말투 기준)
- `팩트체크_<주제>.md` — ❌·확인 못 함이 남아 있으면 다듬기 전에 멈추고 blog-writer로 돌려보냅니다

## 작업 이력
```
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 다듬기 --상태 진행중
python "<도구>/작업이력.py" 단계 --폴더 "<글 폴더>" --이름 다듬기 --상태 완료 --산출물 원고_<주제>.md 다듬기대조_<주제>.md
```

## 단계

### 1. 보호 문장 정하기 (손대지 않음)
- 카드 번호([S3])가 붙은 문장, 숫자·연도가 든 문장, 따옴표 인용이 든 문장, 영문(고유명사·학명·논문 제목)이 든 문장
- 사람·기관·책 이름이 든 문장(한글 고유명사도 포함 — 스크립트가 못 잡으므로 직접 표시)
- 제목·소제목, 인용구, 참고 자료, 사진 캡션·출처, AI 사용 표기
- 이 문장들은 **글자 하나도 바꾸지 않습니다**(조사·어미 포함). 흐름이 어색하면 앞뒤의 보호되지 않은 문장 쪽을 고칩니다.

### 2. 나머지 문장 다듬기 — 무엇을 고치나
| AI 티가 나는 습관 | 이렇게 |
|---|---|
| 문단마다 "또한", "더불어", "이처럼", "결론적으로"로 시작 | 꼭 필요한 곳에만 |
| "~라고 할 수 있습니다", "~하는 것이 중요합니다" 반복 | 바로 말하기("~입니다") — 단, 원문이 일부러 조심스럽게 쓴 곳(추측·단서)은 그대로 |
| 번역투: "~에 대해", "~를 통해", "~에 있어서", "~되어지다" | 우리말 어순으로 |
| 세 가지씩 나열하는 버릇, 같은 뜻 낱말 겹치기 | 하나로 |
| 문단 끝마다 앞 내용을 다시 요약하는 문장 | 빼기(사실이 없는 문장일 때만) |
| 지나친 꾸밈말("매우", "정말", "놀라운"), 느낌표·이모지 | 줄이기 |
| 너무 긴 문장(60자 넘게 이어짐) | 둘로 나누기 — 나눌 때 주어를 두 번째 문장에도 남기기 |
- 우리 단체 기준예시의 말투(정중한 설명체 '~습니다')를 지킵니다. 설교조를 새로 만들지 않습니다.

### 3. 한국어에서 특히 조심할 것 (뜻이 잘 바뀌는 곳)
- **앞부분 생략**: 주어·조건절("~에 따르면", "1997년 연구에서")을 빼면 누가 한 말인지, 언제의 일인지가 바뀝니다. 문장 앞부분은 함부로 빼지 않습니다.
- **은/는 ↔ 이/가**: 대조·초점이 바뀝니다("교진추는 지적했다" vs "교진추가 지적했다").
- **부정 표현**: "않/없/못/아니"가 하나만 빠져도 뜻이 반대가 됩니다. 이중 부정을 줄일 때 특히 조심.
- **단정 ↔ 추측**: "~로 보입니다", "~ㄹ 수 있습니다"를 단정으로 바꾸면 출처보다 세게 말하게 됩니다.
- **인용의 주어**: "리처드슨은 ~라고 썼다"를 "~이다"로 바꾸면 인용이 단체의 단정으로 바뀝니다.
- **시점**: "오늘날"(1998년 서한의 '오늘날')을 지금으로 읽히게 바꾸지 않습니다.

### 4. 기계 대조 → 자동 복원
```
python "<스킬 기본 폴더>/scripts/문장대조.py" 원고_<주제>_다듬기전.md 원고_<주제>_다듬음.md --출력 다듬기대조_<주제>.md --복원본 원고_<주제>_다듬음.md
```
- **자동 복원**: 보호 문장이 바뀌었거나, 숫자·인용·영문·카드 번호가 든 문장이 빠졌거나 새로 생기면 스크립트가 원문으로 되돌립니다.
- **확인 필요**: 부정 표현 수 변화, 단정↔추측 변화, 앞부분(첫 두 어절) 사라짐, 주어·화제 사라짐, 길이 40% 넘게 줄어듦, 새 문장 — 표로 보여 줍니다.

### 5. 뜻 대조 (사람 눈으로)
- '확인 필요' 문장을 하나씩 원문과 나란히 놓고 **뜻이 같은지** 봅니다: 누가 / 언제 / 무엇을 / 얼마나(단정·추측) / 긍정·부정.
- 하나라도 다르면 **원문으로 되돌립니다**(고쳐서 맞추지 말고 되돌리기). 되돌린 문장은 `다듬기대조_<주제>.md` 끝의 '되돌린 목록'에 사유와 함께 적습니다.
- 다 끝나면 다듬은 원고를 확정본 `원고_<주제>.md`로 저장하고(다듬기 전 판은 `원고_<주제>_다듬기전.md`로 보관), blog-writer 규칙대로 **배치 JSON을 다시 만듭니다**.
- 보호 문장이 하나도 바뀌지 않았으므로 팩트체크를 다시 할 필요는 없습니다. 단, 사람 판단으로 보호되지 않은 문장에 사실이 섞여 있었다면 그 문장만 blog-factcheck 2차 검증에 넘깁니다.

## 출력
- `원고_<주제>.md`(다듬은 확정본), `원고_<주제>_다듬기전.md`(보관), `다듬기대조_<주제>.md`(대조표 + 되돌린 목록), 다시 만든 `배치_<주제>.json`
- 보고: 다듬은 문장 수 / 자동 복원 수 / 뜻이 바뀌어 되돌린 문장(목록) / 그대로 둔 보호 문장 수

## 스스로 점검
- [ ] 보호 문장(사실·숫자·인용·고유명사·제목·출처·AI 표기)이 글자 그대로다
- [ ] '확인 필요'를 모두 뜻 대조했고, 뜻이 바뀐 것은 원문으로 되돌렸다
- [ ] 새 사실·새 단체 입장·새 꾸밈 인용이 없다
- [ ] 기준예시의 말투와 어울린다(설교조 없음)
- [ ] 배치 JSON을 다시 만들었다

## 하지 않는 것
- 사실·숫자·인용·이름이 든 문장 고치기, 문장 순서를 크게 바꾸기, 문단 통째로 다시 쓰기
- 다듬으면서 출처보다 세게(단정) 말하기, 조심스러운 표현을 지우기
- 'AI 티를 없앤다'며 AI 사용 표기를 빼거나 흐리기
- 공개 스킬·글을 라이선스 확인 없이 가져오기

## 예시 — 되돌린 목록
| # | 원문 | 다듬은 문장 | 판정 | 사유 |
|---|---|---|---|---|
| 1 | 교진추는 이 문제를 지적해 왔습니다. | 이 문제는 꾸준히 지적돼 왔습니다. | 되돌림 | 주어 '교진추는'이 사라져 누가 지적했는지 바뀜 |
| 2 | 결론을 내리기는 어렵지 않습니다. | 결론은 쉽지 않습니다. | 되돌림 | 부정 표현이 바뀌어 뜻이 반대 |
