# 수리 프롬프트 카드 (막혔을 때 그대로 복사해 쓰기)

> 오류가 나면 Claude는 멈추고 그 단계를 '실패'로 기록합니다. 아래 문장을 Code 탭에 붙여 넣으세요. `<글 폴더>`만 바꾸면 됩니다.

| 상황 | 이렇게 말하기 |
|---|---|
| 무엇이 어디서 멈췄는지 모를 때 | `<글 폴더>`의 작업이력을 보여 주고, 어느 단계에서 왜 멈췄는지 쉬운 말로 설명해줘. |
| 오류 원인을 찾아 고치고 이어 할 때 | 로그/오늘 날짜.log의 마지막 오류를 분석해서 원인을 찾고 고친 다음, 작업이력.py 이어하기로 그 단계부터 다시 실행해줘. 앞 단계 산출물은 다시 만들지 마. |
| 같은 단계만 한 번 더 | `<글 폴더>`의 '팩트체크' 단계만 다시 해줘. 자료조사와 원고는 그대로 써. |
| 처음부터 다시(앞 결과가 엉망일 때) | `<글 폴더>`를 처음부터 다시 하고 싶어. 지금까지 산출물은 작업이력.py 처음부터로 보관한 뒤 시작해줘. |
| 학술 API가 막혔을 때(429·네트워크) | 인용검증을 --캐시 를 써서 다시 돌려줘. 서버가 오래 기다리라고 하면 그 항목은 '확인 못 함'으로 두고 나머지를 먼저 끝내줘. |
| 팩트체크에서 걸린 문장 고칠 때 | 팩트체크 판정표의 ❌·⚠️ 문장만 고쳐줘. 다른 문장은 한 글자도 바꾸지 말고, 고친 목록을 표로 보여줘. 그다음 바뀐 문장만 다시 검증해줘. |
| 근거가 부족하다고 나왔을 때 | C9 주장 하나만 보강 조사해줘. 자료조사 전체를 다시 하지는 마. |
| 다듬은 뒤 뜻이 바뀐 것 같을 때 | 다듬기 대조표에서 '확인 필요' 문장을 원문과 하나씩 비교해서, 뜻이 바뀐 건 원문으로 되돌리고 되돌린 목록을 보여줘. |
| 미리보기 그림이 안 보일 때 | 미리보기를 --열기 로 기본 브라우저에서 열어줘. (Code 탭 Browser 창에서 보려면 --이미지 내장) |
| 패키지가 '누수'로 멈췄을 때 | 배치 JSON에서 [S숫자]·[담당자 확인·내부용 문구가 남은 곳을 찾아 보여줘. 단체 입장 문장은 내가 확인할게. |
| 임시저장이 중간에 멈췄을 때 | 블로그 도우미 확장이 보낸 결과를 읽고 몇 번째 단계에서 왜 멈췄는지 알려줘. 내가 브라우저에서 확인한 뒤 그 단계부터 다시 하자. |
| 네이버 화면이 바뀐 것 같을 때 | 확장 선택자를 지금 화면에 맞게 고쳐야 할 것 같아. 어떤 단계가 실패했는지 정리해서 강사에게 보낼 메모로 만들어줘. |
