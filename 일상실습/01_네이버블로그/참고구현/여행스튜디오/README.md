# 여행 스튜디오 — 완성본(참고 구현, 규약 v2)

여행 사진 폴더를 고르면 Claude가 시간순으로 정리하고, 고르기·구성안·지도·글·네이버 임시저장까지 도와주는 **내 컴퓨터 안의 작은 웹 화면**입니다.
직접 만들다가 막혔을 때 **비교해 보는 용도**의 완성본입니다. 약속(폴더·파일 모양)은 `문서/여행스튜디오_규약.md`(v2 — 교재의 규약 사본, `공용가져오기.py`가 최신으로 맞춤), 네이버 연동은 `공용/발행API.md`를 따릅니다.

## 1. 켜는 법

| | Windows | Mac (실기 미확인) |
|---|---|---|
| 처음 한 번 | (사람이) 이 폴더에서 `python 공용가져오기.py`(공용 파일 복사) → `python 바탕화면아이콘만들기.py` → 바탕화면에 **여행 스튜디오** 아이콘 | `python3 공용가져오기.py` → 터미널에서 `chmod +x 스튜디오실행.command` → `python3 바탕화면아이콘만들기.py` |

- `공용가져오기.py` 는 공용 폴더를 **알아서 찾습니다**: 이 폴더 옆 `../공용` → 교재 저장소의 `../../일상실습/01_네이버블로그/참고구현/공용`(스튜디오를 `실습공간/`에 복사해 쓸 때) → 위쪽 폴더들. 못 찾으면 찾아본 곳과 함께 `--원본` 예를 보여 줍니다: `python 공용가져오기.py --원본 "<교재 폴더>/일상실습/01_네이버블로그/참고구현/공용"`
| 매번 | 바탕화면 아이콘 더블클릭 (또는 `스튜디오실행.pyw` 더블클릭) | 바탕화면의 `여행 스튜디오.command` 더블클릭 |

- 브라우저에 `http://localhost:8765` 가 열립니다. 이 주소는 **내 컴퓨터에서만** 열립니다.
- 이미 켜져 있으면 브라우저만 다시 엽니다. 서버는 검은 창 없이 뒤에서 돕니다(끄려면 컴퓨터를 다시 켜거나 작업 관리자에서 `pythonw` 끝내기).
- 필요한 것: Python 3.10 이상(서버는 **추가 설치 없음**). 사진 처리 도구는 `pillow pillow-heif av imagehash mediapipe py-staticmaps tzdata`(+FFmpeg)를 씁니다 — 설치 한 줄(가상환경 권장): `python -m pip install pillow pillow-heif av imagehash mediapipe py-staticmaps tzdata`
- **아이폰 사진(HEIC)이 있으면 `pillow-heif`가 꼭 필요합니다.** 없으면 ‘사진 목록 만들기’가 첫 단계에서 멈추고 설치 방법을 알려 줘요. 사람이 터미널(Windows: PowerShell·명령 프롬프트 / Mac: 터미널)에서 직접: `python -m pip install pillow-heif` (Mac은 `python3 -m pip install pillow-heif`) — 끝나면 화면에서 다시 누르세요. (Claude는 설치 명령을 실행하지 않아요.) 위의 전체 설치 한 줄에 이미 들어 있습니다.
- 여행 **기간**을 잘못 적었으면(시작이 사진보다 뒤 등) ② 사진 화면 위의 **[기간 고치기]**로 고친 뒤 ‘사진 목록 다시 만들어 달라기’를 누르세요. `여행정보.json`을 직접 열 필요가 없어요.
- 여행 폴더 이름(여행ID)은 한글·영문·숫자·`-`·`_`만 씁니다(`( )` 같은 기호는 `_`로 바뀜). 예전에 만든 폴더는 이름을 바꾸지 않아요.
- 오른쪽 위 **[어둡게]/[밝게]** 로 화면 밝기를 바꿉니다(고른 것은 브라우저에 기억, 처음엔 컴퓨터 설정대로).

## 2. Claude와 연결하기

화면 오른쪽 위 표시를 보세요.

| 표시 | 뜻 |
|---|---|
| ● Claude 연결됨 | Claude가 기다리는 중. 버튼을 누르면 바로 시작해요 |
| ● Claude 작업 중 · … % / ● 블로그 도우미 · … | Claude 또는 블로그 도우미 확장이 일하는 중 |
| ● 연결 안 됨 · Claude 연결하기 | 이 빨간 단추를 누르세요 |

[Claude 연결하기] → Claude 앱이 열리면 폴더 확인 → 입력칸의 **"여행 스튜디오 연결해줘"** 를 보고 Enter.
앱이 안 열리면: Claude 앱 **Code** 탭에서 이 폴더를 열고 `여행 스튜디오 연결해줘`라고 입력하세요. 그 Claude 창은 **켜 두기만** 하면 됩니다.

**어떻게 움직이나요?** 화면 버튼을 누르면 `작업함/요청/`에 쪽지(파일)가 생깁니다. Claude는 `도구/대기.py`를 뒤에서 켜 두는데, 이 스크립트는 쪽지가 생기는 순간 끝나면서 Claude를 깨웁니다. Claude는 쪽지를 처리하고 **다시 대기.py를 켜서** 다음 쪽지를 기다립니다.

> **처음에 '실행해도 될까요?' 승인 창이 뜨면**, 창에 적힌 명령이 `python 도구/…`·`python .claude/skills/studio-connect/작업함.py …`·`python 스튜디오실행.pyw …` 처럼 **이 폴더의 정해진 명령일 때만 '항상 허용'(Yes, and don't ask again)** 을 고르세요. 그러면 다음부터는 묻지 않고 자동으로 돌아갑니다. 그 밖의 명령(공용가져오기·미리보기·서버 직접 실행·curl·지우기 등)은 '이번만' 또는 거절하세요 — '항상 허용'한 명령은 Claude가 속았을 때(사진·글 속 숨은 지시)도 묻지 않고 실행돼요. (이 폴더를 처음 열 때 묻는 '신뢰' 창에서 허용해 두면 `.claude/settings.json`에 적힌 명령은 처음부터 묻지 않아요.)
>
> **사람만 하는 일**: 글 승인, 자동 예약 발행 켜기(컴퓨터에 뜨는 확인 창에서 [예]), 예약 발행, 질문에 답하기, 공용 파일 갱신(화면 위쪽 [공용 파일 갱신]). `.claude/settings.json` 이 Claude가 이런 파일(`설정.json`·`.claude/`·`공용/`·`도구/`·`서버/`·답변)을 고치지 못하게 막아 두었어요.

감시가 꺼져 있던 동안 누른 버튼은 쌓여 있다가, Claude에게 **"스튜디오 요청 처리해줘"** 라고 하면 한 번에 처리됩니다.

## 3. 화면 순서

① **시작** 여행 카드·[새 여행 만들기](내 PC 폴더 고르기 창) → ② **타임라인·고르기** 사진을 누를 때마다 사용 → 대표 → 제외 → ③ **질문** Claude가 애매한 것을 묻는 카드 → ④ **구성안** 세 안 중 하나를 [이 안으로 정하기] → 글이 몇 편(편ID)인지 정해짐 → ⑤ **지도·장소** 이름 확인·숙소 숨기기 → ⑥ **글** 편마다 [이 편 글쓰기], 네이버식 미리보기(PC/모바일), 블록별 [고쳐줘], **[이 글 승인]** → ⑦ **발행** [확장 연결]·설정·[네이버 임시저장]·단계별 진행·[다시 시도] → ⑧ **영상**(선택) → ⑨ **작업 이력** 성공/실패/재시도 완료/재시도 불가, [다시 시도]·[처음부터]·[로그 보기]·수리 프롬프트

원본 사진은 **읽기만** 합니다. 작업은 `여행/<여행ID>/작업/`의 사본으로 하고, 네이버에는 **임시저장까지만** 합니다(로그인·발행은 사람).

## 4. 네이버 임시저장 — 블로그 도우미 확장 (Chrome 또는 Edge)

1. 확장(`참고구현/크롬도우미/`)을 **Chrome 또는 Edge**에 설치하고, 그 브라우저에서 네이버에 **직접 로그인**해 둡니다.
2. 화면 ⑦ **설정**: 글쓰기 화면을 열 브라우저(Chrome / Edge / 기본 브라우저)와 **블로그 아이디**를 적습니다.
3. 화면 ⑦ **[확장 연결]** → 6자리 연결 코드(5분, 한 번만)를 확장 팝업에 넣습니다. 한 번 연결하면 단체 블로그의 발행서버에서도 그대로 됩니다(연결 정보는 `~/.gea-blog-helper/`, 해시만 저장).
4. 글을 미리보기로 확인 → **1단계 [발행 패키지 만들어 달라기]**: Claude가 GPS·기기 정보를 지운 사진·영상 사본과 발행 패키지**만** 만듭니다(네이버 쪽은 아무것도 안 함) → **2단계 [네이버 임시저장]**(사람이 누름): 설정한 브라우저로 글쓰기 화면이 열리고, 확장이 제목·본문·사진·장소·태그를 채워 **'저장'까지** 합니다. 단계마다 화면 ⑦에 표시됩니다.
5. 멈추면 그 단계와 이유·고치는 방법이 보이고 **[다시 시도]**(그 단계부터)·[처음부터]를 누를 수 있습니다.
6. 끝나면 네이버의 임시저장 글에서 **모바일 화면을 확인**하고 **'발행'은 직접** 누릅니다.
7. 같은 글은 한 번만: 채우는 동안에는 [네이버 임시저장]이 꺼져 있고, 이미 임시저장한 글·실패한 글은 누르면 확인 창이 뜹니다(다시 하면 네이버에 **새 글로 하나 더** 저장됨 — 실패한 글은 [다시 시도]가 먼저).
8. 글 사이 간격: 한 글을 끝낸 뒤 설정 `편사이간격분`(기본 10분) 동안은 다음 글을 채우지 않습니다. 기다리는 동안 ⑦에 **'다음 가능 시각'** 이 보입니다.

**AI 사용 표시**: 네이버 'AI 활용 설정'은 글 단위가 아니라 **사진·영상마다** 있는 스위치(AI로 만든 이미지·영상·오디오가 대상)라 블로그 도우미가 켜 주지 않습니다. 여행 사진은 직접 찍은 것이라 **기본은 끔**이고, AI로 만들거나 바꾼 그림을 넣었을 때만 ⑥ 글 화면의 체크박스로 표시하세요 — 임시저장 때 도우미가 '사진·영상마다 직접 켜 주세요'라고 알려 주고, 스위치는 사람이 켭니다. 대신 글을 AI 도움으로 쓴 사실은 **글 끝 문구**("이 글은 AI의 도움을 받아 사진을 정리하고 초안을 쓴 뒤, 직접 확인하고 다듬었습니다.")로 늘 알립니다.

동영상: 패키지에는 메타(위치·기기·만든 시각)를 지운 영상 사본이 **동영상 묶음**으로 들어가고, 블로그 도우미(v0.3.0~)가 네이버 '동영상'으로 올립니다(업로드·인코딩 동안 ⑦에 '처리 중', 최대 30분 — 실측 전). 안 되면 `발행/사진묶음_<편ID>/<번호>_video/` 의 mp4 를 '동영상' 버튼으로 직접 올려도 됩니다. 16MB 넘는 동영상은 서버가 나눠 보냅니다(Range 지원).

자동 예약 발행은 설정에서 따로 켜야 하고(약관 위험 안내 확인 + **컴퓨터에 뜨는 확인 창에서 [예]**), 화면에서 **[이 글 승인]** 한 글만(서버가 승인에 서명 — 승인 뒤 글이 바뀌면 무효), 화면 ⑦에서 사람이 누를 때만, 10분 단위 시각으로만 됩니다. Claude는 예약 작업을 만들지 않습니다.

**Claude 의 브라우저 도구 주의**: Claude in Chrome·Claude 앱의 브라우저 창이 `localhost`(여행 스튜디오 화면)를 열지 못하게 해 두세요(허용 사이트에서 빼기). 승인·예약은 컴퓨터에 뜨는 확인 창에서 마우스로 한 번 더 눌러야 해서 화면만 대신 눌러서는 안 되지만, 화면은 사람만 쓰는 곳이에요.

**브라우저 확장 주의**: 스튜디오를 여는 브라우저 프로필에는 '모든 사이트에서 읽고 변경' 권한을 가진 확장(쿠폰·번역 등)을 두지 마세요. 서버가 화면에만 주는 열쇠(메모리에만, 켤 때마다 새로)로 다른 확장·사이트의 직접 요청은 막지만, 모든 사이트 권한 확장은 화면 자체를 읽을 수 있어요.

```
여행스튜디오/
├── 스튜디오실행.pyw / 스튜디오실행.command   더블클릭 실행(Windows / Mac)
├── 바탕화면아이콘만들기.py                    --대상 <폴더> 로 다른 곳에 만들기(시험용)
├── 공용가져오기.py                            공용 폴더를 찾아(또는 --원본) 공용 파일을 공용/ 으로 복사
├── 아이콘/  studio.ico(16~256) · studio.png(256) · studio_512.png
├── CLAUDE.md                                 이 폴더에서 Claude가 지킬 규칙
├── .claude/settings.json                     대기.py·도구·서버 실행과 작업함·여행 쓰기만 허용(승인 창 줄이기)
├── .claude/skills/studio-connect/            SKILL.md(연결·처리 절차) + 작업함.py(진행·알림·질문·완료·이력·로그·발행·판정)
├── .claude/skills/naver-draft/               블로그 도우미 확장으로 임시저장(공용 스킬의 스튜디오용 복사본)
├── 서버/server.py · 서버/발행연동.py         화면 + /api (표준 라이브러리만, 127.0.0.1:8765) · 공용 발행 모듈 연결
├── 서버/화면/  index.html · app.js · style.css (빌드 과정 없음, 밝게/어둡게)
├── 공용/  미리보기.py · 템플릿.html · 발행서버.py · 발행API.md · 발행묶음_API.md   (단체 블로그와 같은 파일)
├── 도구/대기.py                              작업함 기다리기(나머지 사진 도구도 이 폴더에)
├── 작업함/  요청/ 질문/ 답변/ 처리완료/ 상태.json   (처음 켤 때 자동으로 생김)
├── 여행/<여행ID>/                            여행정보·목록·장소·작업이력·원고(구성안·편목록·배치_<편ID>)·발행
├── 로그/YYYY-MM-DD.log                       모든 단계 기록
├── 설정.json                                 화면 ⑦ 설정 — 단체 블로그와 같은 키: 블로그ID·브라우저·자동예약발행·편사이간격분(10)·예약최소여유분(15)·중단판정분(10)
└── 꿀팁노트.md                               사용자가 말한 꿀팁만 기록
```

## 6. 서버 주소(API) 한눈에

| 주소 | 하는 일 |
|---|---|
| `GET /` | 화면 |
| `GET·POST /api/여행` | 여행 목록(편 상태 포함) / 새 여행(폴더 고르기 창) |

**보안(2026-10-08 검수 반영)**: 브라우저의 요청은 화면 열쇠(`X-Studio-Key` 머리 또는 화면이 받은 HttpOnly·SameSite=Strict 쿠키)가 있어야 `/api/`·`/파일/`을 줌. 주소창·확장의 요청(`Sec-Fetch-Site: none`)은 화면(`/`)만. 사람 동작(승인·설정·결정·답변·구성안 고르기·알림·공용 갱신 …)의 POST 는 화면 열쇠가 있어야 하고, 열쇠 없는 프로그램(Claude 도우미)은 임시저장 작업 만들기·다시 시도만(예약 제외). 승인·자동 예약 허락은 공용 모듈(ApprovalStore)이 서버만 아는 키(`~/.gea-blog-helper/서명키`)로 서명·등록(`승인.json`·`자동예약허락.json`)하고 예약 때 확인, 자동 예약 발행 켜기는 데스크탑 확인 창. 예약 작업은 화면 열쇠를 확인한 요청만 공용 모듈에 '사람 경로'(human=True)로 넘김. 화면에 CSP, `/파일/` 은 그림·영상·json·txt 만 바로 보여 주고 나머지는 내려받기(sandbox), 미리보기는 매번 이름 모를 임시 파일로 만들어 바로 읽고 지운 뒤 서버 메모리에만 둠(원고/ 에 심은 html 을 내주지 않음), 글꼴은 컴퓨터 글꼴(외부 요청 없음).
