## ① 블로그 확인 인터뷰

### 1.1 왜 블로그부터 확인하나

🧩 **비유**: 새로 온 홍보 담당 신입에게 첫날 해 주는 **인수인계**입니다. "우리 블로그 주소는 여기고, 카테고리는 이렇게 나뉘고, 글은 누가 쓰고 누가 확인하고, 독자는 이런 분들이에요." 이걸 모르면 아무리 똑똑한 신입도 엉뚱한 글을 씁니다.

Claude도 같습니다. 블로그의 **카테고리 이름**은 나중에 확장이 카테고리를 고를 때 글자 하나까지 맞아야 하고, **독자**에 따라 문장 수준이 달라지고, **담당**이 정해져야 사람 확인 지점을 세울 수 있습니다. 인터뷰 결과는 A 교재 2~3회차 카드에서 프로젝트 카드와 운영 규칙(CLAUDE.md)의 재료가 됩니다.

**우리 단체 예**: 교진추 블로그라면 "자료실 > 생물학적 진화" 같은 카테고리 이름, 교사·학부모 독자, 약 5일 간격 발행, 칼럼은 필자 원고 그대로라는 사정을 먼저 알려 주는 것입니다.

💭 **확인 질문**: 우리 블로그 글에서 '발행' 버튼을 누르는 사람은 지금 누구인가요? 그 사람이 바쁠 때는 어떻게 되나요?

튜터(또는 Claude)가 아래 질문을 **선택지로 하나씩** 묻습니다. 모르는 것은 "모름"이라고 답해도 됩니다.

| # | 질문 | 왜 묻나 | 예 |
|---|---|---|---|
| 1 | 네이버 블로그를 지금 운영하나요? | 없으면 개설·비공개 연습부터 | 운영 중 / 만들 예정 / 다른 채널만 |
| 2 | 개인 블로그인가요, 단체 블로그인가요? | 유형 A·B 추천, 말투 | 단체 공식 블로그 |
| 3 | 블로그 주소(블로그 ID)는? | 글쓰기 화면 열기, 기록 | `blog.naver.com/str_bg` |
| 4 | 카테고리 이름은? (띄어쓰기까지) | 확장이 이름으로 카테고리를 고름 | 자료실 > 생물학적 진화 |
| 5 | 얼마나 자주 올리나요? | 주제판·예약 작업 일정 | 주 1편, 칼럼은 원고 오는 대로 |
| 6 | 쓰는 사람·확인하는 사람·'발행'을 누르는 사람은? | 사람 승인 지점 | 사무국 간사 / 사무총장 / 간사 |
| 7 | 주로 누가 읽나요? | 문장 수준·용어 풀이 | 중·고등 교사, 학부모 |
| 8 | 지금 가장 시간이 드는 일은? | 자동화 우선순위 | 자료 찾기, 사진 고르기, 출처 정리 |
| 9 | 계정은 어떻게 쓰나요? | 로그인 담당, 안전 | 개인 계정 / 단체회원 계정 |

```
일상실습/01_네이버블로그/00_시작_블로그확인.md의 '블로그 확인 인터뷰'를 해줘. 질문표 10개를 선택지로 하나씩 물어보고, 모르는 건 '확인 필요'로 남겨줘.

```

카테고리 이름은 블로그 화면을 캡처해 입력창에 끌어다 놓고 "이 화면의 카테고리 이름을 그대로 옮겨줘"라고 하면 글자를 잘못 옮길 일이 줄어듭니다.

### 1.3 블로그가 아직 없다면

- **개설은 선생님이 직접** 합니다. 튜터와 Claude는 네이버 계정을 만들거나 로그인하지 않습니다. 개설 화면 순서는 네이버 안내를 따르고, 막히면 네이버 고객센터 도움말을 함께 찾아 읽습니다(화면 문구는 조금 다를 수 있습니다).
- **단체 블로그**라면 네이버의 '단체회원' 계정을 검토해 보세요. 관리자가 멤버에게 '멤버 비밀번호'를 발급해 하나의 아이디를 함께 쓰는 방식이고, 멤버끼리 비밀번호를 공유하는 것은 금지입니다.
- 블로그가 생기기 전에도 A 실습은 **미리보기까지** 그대로 할 수 있습니다. 네이버 연결은 블로그가 생긴 뒤에 붙입니다.
- 처음 몇 편은 **비공개로 발행해 연습**합니다. 발행 설정의 공개 설정에서 '비공개'를 골라 발행하고, 내 블로그에서 실제 모습을 본 뒤 괜찮으면 '전체 공개'로 바꿉니다. 공개로 바꾼 글이 검색에 반영되기까지 최대 1일이 걸릴 수 있습니다.
- 블로그 소개글은 정확히 써 두세요. 네이버는 2026-05-14부터 공공기관·교육기관·공익단체 등 일부 공식 블로그에 "AI 출처 정보"(어떤 기관의 공식 블로그인지 설명)를 붙이기 시작했고, 블로그 소개글과 글을 종합한다고 밝혔습니다.

## ② 유형 고르기 — A와 B

🧩 **비유**: A는 **매주 나오는 단체 소식지 편집국**을 꾸리는 일이고, B는 **여행 앨범을 한 권 엮는 작업실**을 차리는 일입니다. 편집국은 회차마다 조금씩 키워 가고, 작업실은 한 번 크게 차려 놓고 여행마다 씁니다.

| | **A 단체 블로그 정기 발행** | **B 여행 블로그 스튜디오** |
|---|---|---|
| 이런 분께 | 단체 블로그에 정기적으로 자료·소식·칼럼을 올리는 실무자 | 개인 여행·단체 탐방 사진을 일자별 글로 엮고 싶은 분 |
| 형식 | **관통형** — 2~10회차 단계 카드 + 수료자용 몰아서 경로(3번) | **독립 심화** — Part 1~9, 3번에 나눠(총 약 5~6시간) |
| 핵심 작업 | 자료조사 → 작가 → 팩트체크 → 다듬기 → 이미지 → 미리보기 → 임시저장 | 사진 모으기 → 시간순 정리 → 흐린 사진 고르기 → 이야기 구성 → 글·사진 배치 → 임시저장 |
| 화면 | Code 탭 대화 + 스킬 + 미리보기 | 내 PC에서 여는 웹 화면 '여행 스튜디오'(GUI) + Code 탭 |
| 남는 것 | 운영 규칙, 카테고리 설정, 스킬 5개, 설계서, 주간 초안 예약 작업 | 여행 스튜디오, 여행기 스킬, 꿀팁 노트, (선택) 돌아보기 영상 |
| 익히는 기능 | CLAUDE.md, Git, 스킬, 서브에이전트·reviewer, 예약 작업 | Plan 모드, 이미지 읽기, 질문 카드, 화면 설계, 훅 |
| 언제 | 2회차에 관통 프로젝트로 고르면 가장 자연스러움 | 3회차 이후 언제든, 5·8회차를 마친 뒤 권장 |

- **둘 다 할 수 있습니다.** 블로그 연동(확장·연결 코드)은 공통이라, 하나를 해 두면 다른 하나가 빨라집니다.
- 단체 업무가 목적이면 A부터, 개인 생활에서 먼저 재미를 느끼고 싶으면 B부터 권합니다.
- 이미 다른 관통 프로젝트를 고르셨다면 A는 수료 뒤 몰아서 경로로, B는 아무 때나 할 수 있습니다.

```
내 프로필(내_학습기록/학습자_프로필.md)과 방금 저장한 블로그 확인 카드를 보고, 유형 A와 B 중 무엇부터 하면 좋을지 이유 3가지로 추천해줘. 내가 지금 몇 회차인지도 고려해줘.
```

블로그 실습 준비물을 점검해줘. 이 PC에 Python, Pillow, Git, Chrome, Edge, OpenAI Codex CLI, FFmpeg가 있는지 확인해서 표로 보여줘(설치는 아직 하지 마). 없는 것 중 내가 고른 유형에 꼭 필요한 것만 "설치해 드릴까요?"라고 물어봐줘.

- 실습 중 **같은 명령이 되풀이되는 승인 창**(예: B의 대기 스크립트는 쪽지마다 다시 실행)은 무엇을 실행하는지 읽고 **'항상 허용'**(Yes, and don't ask again)을 고르면 다음부터 자동으로 돕니다.
- **ChatGPT Plus**는 2026-10-07 한국어 요금 페이지 기준 월 ₩29,000으로 표시되어 있습니다(부가세 포함 여부는 확인 필요). Free 플랜은 Codex 이미지 자동화를 쓸 수 없고 Go 플랜은 확인 필요라 **Plus 이상**을 기준으로 합니다. 없으면 **무료 사진**으로 충분합니다.

## ④ 꼭 알아야 할 사실 5가지

### 사실 1. 네이버에는 공식 발행 API가 없고, 약관은 자동 게시를 금지합니다 → 로그인과 '발행'은 사람

🧩 **비유**: 편지는 동료가 써서 봉투에 넣어 줄 수 있지만, **우체통에 넣는 것은 본인**입니다.

- 네이버 블로그의 공식 글쓰기 API는 **2020-05-06에 종료**되었고, 대신할 공식 발행 수단이 없습니다.
- 네이버 이용약관(2026-10-01 시행)은 네이버가 허락하지 않은 자동화 수단(매크로·봇 등)으로 로그인하거나 글을 올리는 것을 금지합니다. 하루 발행 수에는 공개되지 않은 상한이 있고, 한꺼번에 많이 올리면 보안 캡차가 뜹니다.
- 그래서 이 실습은 **로그인은 사람, 글 채우기와 '저장'(임시저장)은 블로그 도우미 확장, '발행'은 사람**으로 나눕니다. 한 번에 한 편씩만 합니다.
- Claude가 브라우저를 직접 조작하는 방법(Claude in Chrome, Code 탭 안의 Browser 창)은 네이버에서 '안전 제한'으로 막혔다는 관찰과 보고가 있어 기본 경로로 쓰지 않습니다.
- 사람이 승인한 글만 확장이 예약 발행하는 **선택 기능**이 있지만 기본은 꺼져 있고, 약관 위험을 이해한 뒤에만 켭니다(A 10회차 카드).

### 사실 2. AI를 썼다면 밝히는 것이 권고입니다

🧩 **비유**: 사진을 보정했으면 "보정함"이라고 적는 것처럼, 독자에게 **만든 과정**을 솔직히 알리는 것입니다.

- 네이버 검색은 생성형 AI를 썼다는 이유만으로 불이익을 주지 않는다고 밝혔고, **AI를 활용했다면 그 사실을 문서에 명시하라고 권고**합니다(2024-02-28). 다만 AI로 비슷한 글을 대량으로 만드는 것은 어뷰징으로 봅니다.
- 네이버의 **'AI 활용 설정'** 은 AI로 만들거나 편집한 **이미지·영상(오디오 포함)** 이 있을 때 작성자가 스스로 켜는 표시이며, 권장 사항입니다(에디터 안의 정확한 위치는 확인 필요).
- AI기본법의 생성물 표시 의무를 지는 사람은 '인공지능사업자'입니다. AI로 쓴 글을 자기 블로그에 올리는 단체는 '이용자'로 보는 해석이 자연스럽습니다(법률 자문 아님).
- 그래서 이 실습의 **단체 표준**: 모든 글 끝에 AI 사용 표기 한 줄, AI로 만든·바꾼 이미지에는 캡션 표기 + 'AI 활용 설정' 켜기.

### 사실 3. 사진은 빌린 물건이고, 얼굴은 그 사람의 것입니다

🧩 **비유**: 무료 사진은 **도서관에서 빌린 책** — 빌릴 때의 조건(라이선스)을 지켜야 합니다. 사진 속 얼굴은 **그 사람의 것** — 그림으로 바꿔도 주인은 그대로입니다.

- 무료 이미지는 라이선스를 확인하고 출처대장에 기록합니다. 후원 링크가 있는 단체 블로그는 보수적으로 **NC(비영리 한정) 라이선스를 쓰지 않고**, Unsplash는 API로 받지 않습니다(네이버에 올리는 방식과 Unsplash API 조건이 맞지 않음).
- 대법원 2004다16280 판결은 초상권 침해 방식에 **"그림묘사"** 를 명시합니다. **삽화로 바꿔도 얼굴을 알아볼 수 있으면 초상권 문제는 남습니다.**
- 만 14세 미만 아동의 개인정보를 처리하려면 **법정대리인(보호자) 동의**가 필요합니다(개인정보 보호법 제22조의2).
- 얼굴이 식별되는 사진은 **동의를 확인하기 전에는 외부 AI(삽화 변환)에 올리지 않습니다.** OpenAI는 실사 아동 사진 편집을 허용하지 않는다고 밝힌 적이 있어(2025-03), 아이가 나온 사진은 변환이 거절될 수 있습니다. 동의가 없으면 뒷모습·손·먼 풍경 사진을 씁니다.
- Claude는 이미지를 직접 만들거나 고치지 못합니다. 이미지 만들기는 외부 AI(선택), Claude는 고르기·라이선스 확인·기록을 맡습니다.

### 사실 4. 사진에는 보이지 않는 꼬리표가 붙어 있습니다 — 개인정보

🧩 **비유**: 휴대폰 사진에는 **찍은 장소(GPS)가 적힌 보이지 않는 꼬리표**가 붙어 있습니다. 그대로 올리면 집이나 숙소 위치를 알려 주는 셈이 될 수 있습니다.

- 올리는 사진은 사본을 만들어 **위치 정보를 지웁니다.** 네이버가 올릴 때 지워 준다는 말은 비공식이라 믿지 않고 직접 지웁니다(발행 패키지 단계가 자동으로 함).
- 숙소·집·아이 학교 위치, 행사 참가자 이름, 연락처는 글과 지도에 넣지 않습니다.
- **보안국가 선교사 정보**(실명·국가·얼굴·교회명·종교 용어)는 AI에 넣지 않습니다(5회차 원칙).
- AI에게 보낸 내용은 학습에 쓰이지 않도록 설정해도 **전송·처리는 일어납니다.** 실제 자료를 쓸 때는 5회차 분류(보낼 것/가릴 것/보내지 말 것)를 먼저 합니다.

### 사실 5. 한 편에도 사용량과 시간이 듭니다

🧩 **비유**: 동료에게도 **하루 근무 시간**이 있습니다. 한 번에 몰아서 시키기보다 단계마다 끊어 맡기는 것이 오래 갑니다.

- 강사 리허설에서 자료조사부터 발행 패키지까지 약 35분이 걸렸고, 학습자가 직접 확인하며 하면 **한 편에 60~90분**을 잡는 것이 안전합니다(추정). 두 번째 글부터는 빨라집니다.
- 사용량은 모델 선택기 옆 **사용량 링**에서 봅니다. 단계마다 결과를 파일로 남기고, 길어지면 `/handoff` 뒤 새 세션에서 이어 갑니다.
- Codex로 이미지를 만들면 ChatGPT 구독 한도를 일반 작업보다 **평균 3~5배 빨리** 씁니다(장수 기준 공식 수치는 없음).
- 같은 계정에 하루 여러 편을 몰아 올리지 않습니다. 네이버는 기계적으로 대량 생산된 글을 검색 품질 저하 사유로 봅니다.

- 순서: 프로필·진도 읽기 → ① 인터뷰(한 번에 한 질문, 선택지) → 기록 저장 → ② 유형 추천 → ③ 준비물 점검(설치는 묻고 나서) → ④ 사실 5가지(한 번에 하나, 확인 질문 하나) → ⑤ 다음 문서 안내와 진행 기록 한 줄.
- 1~2회차를 마치지 않은 학습자는 1회차(권한 모드·승인 창)와 2회차(인터뷰 받기)를 먼저 권합니다. 막지는 않습니다.
- 학습자가 이미 회차 중간이면 A의 '따라잡기' 문장으로 안내하고, 진도표의 본 회차 진행은 그대로 둡니다.

### 진행 예시 (교진추 간사, 🌱, 4회차 진행 중)
```
튜터: 🗺️ 일상 실습 ① · 시작 ①/⑤ · 블로그 확인
      먼저 우리 블로그를 소개받을게요. 지금 네이버 블로그를 운영하고 계신가요?
      1) 운영 중  2) 만들 예정  3) 블로그 없이 다른 채널만
학습자: 1
튜터: 주소를 알려 주세요. 블로그 첫 화면 주소창의 blog.naver.com/ 뒤 부분이면 됩니다.
학습자: str_bg
튜터: 카테고리 화면을 캡처해서 여기에 끌어다 놓아 주시겠어요? 띄어쓰기까지 그대로 옮겨 적을게요.

튜터: 블로그 확인 카드를 내_학습기록/일상실습_블로그.md에 저장했습니다.
      지금 4회차를 하고 계시니, A 교재의 '따라잡기'로 2~3회차 카드를 먼저 하고
      4회차 카드부터는 본 학습 뒤에 이어 가시길 권합니다. 괜찮으세요?
```
- 매 응답 첫 줄 위치 표시는 `🗺️ 일상 실습 ① · 시작 ②/⑤ · 유형 고르기`처럼 씁니다(본 회차 진도와 섞이지 않게).

### 확인 질문 답 예시
- 1.1 "발행 버튼은 누가?" → 담당자 이름이 나오면 성공. "그때그때"라면 담당을 정하는 것이 이 실습의 첫 성과라고 짚습니다.
- ② "사람이 꼭 할 일 두 가지" → 로그인·발행(공통), 사진 동의 확인(A), 사진 고르기 확정(B) 중 두 가지.
- ④ "가장 걸리는 것" → 정답은 없습니다. 답한 사실에 맞는 우리 규칙 한 줄(예: "아이 얼굴 사진은 보호자 동의 확인 전 외부 AI 금지")을 CLAUDE.md 후보로 적어 둡니다(A 3회차에서 씀).

### 수준별 설명 가이드
- 🌱 입문: 인터뷰는 질문 10개를 5개씩 두 번에 나눕니다. 사실 5가지는 비유와 "그래서 우리 규칙은 ○○" 한 줄만. 유형은 A의 회차 카드를 기본으로 권합니다.
- 🌿 기초: 사실마다 근거(약관·판결·법 조항)를 한 줄씩 덧붙입니다. A·B 둘 다 계획을 세워 줍니다.
- 🌳 중급: 블로그 도우미 확장이 왜 Claude in Chrome 대신 기본인지(네이버 차단 보고, 사람의 일반 브라우저·직접 로그인, 연결 코드) 구조까지 설명합니다.

### 자주 막히는 지점과 대응
- **"블로그를 대신 만들어 줄 수 있나요?"** → 계정 만들기·로그인은 사람이 합니다. 개설 화면을 함께 보며 무엇을 누를지 설명하는 것까지는 돕되, 대신 입력하지 않습니다. 개설 화면 순서는 조사하지 않았으므로 지어내지 말고, 학습자가 본 화면을 함께 해석합니다.
- **카테고리 이름을 대충 적음** → 캡처 이미지로 받아 글자 그대로 옮깁니다. "자료실 > 생물학적 진화"처럼 상위·하위를 구분해 적습니다.
- **"발행까지 자동으로 해 주세요"** → 사실 1을 다시 설명하고, 선택 기능(자동 예약 발행)은 A 10회차에서 세 조건과 위험을 이해한 뒤에만 다룬다고 안내합니다.
- **ChatGPT Plus를 꼭 사야 하나요?** → 아닙니다. 무료 사진과 단체 사진으로 충분하고, 삽화는 선택입니다. 결제를 권하지 않습니다.
- **브라우저를 둘 다 씀** → 확장을 설치할 브라우저 하나를 정하고, 네이버 로그인도 그 브라우저에서 하게 합니다.
- **Code 탭 Browser 창에서 네이버를 열려고 함** → 이 PC 관찰에서 네이버 주소가 '안전 제한'으로 열리지 않았습니다. 네이버는 학습자의 Chrome·Edge에서만 다룹니다.
- **승인 창이 계속 뜸(Bash/PowerShell 도구 차이)** → 먼저 '항상 허용'을 골랐는지 봅니다. 그래도 뜨면 Claude에게 "명령은 Bash 도구로, 허용 규칙과 같은 글자 모양(상대 경로·따옴표 없이)으로 실행해줘"라고 하게 합니다(여행 리허설에서 PowerShell 도구로 낸 명령이 허용 규칙에 안 맞은 일이 남은 문제로 있음).

### 단체별 메모
- 교진추: 공식 블로그가 확인된 유일한 단체. 홈페이지 글을 며칠 뒤 블로그에 다시 올리는 패턴이 있어 "홈페이지 글 → 블로그판 재구성"이 현실적인 첫 실습입니다. 칼럼은 필자 주장·문체를 고치지 않고 인용·서지만 봅니다.
- 다교연·SHINE: SHINE은 다교연을 통해 통합 관리한다고 소개되어 있으므로, 다교연 블로그를 열 경우 SHINE 영상 소개 카테고리를 함께 설계하는 안을 제안합니다.
- 미션펀드: 보안국가 관련 소식은 블로그 소재에서 기본 제외. 다루려면 민감어 점검 훅(A 단체별 메뉴)을 먼저 만듭니다.
- 다니엘칼리지·엘리온: 학생 사진이 많을 가능성이 큽니다. 사진 동의 대장(A 5회차)과 14세 미만 보호자 동의를 먼저 확인합니다.

### 안전·약관 주의
- 네이버 비밀번호·인증번호·확장 연결 코드를 Claude가 입력하지 않습니다. 학습자가 대화창에 비밀번호를 붙여 넣으려 하면 말리고, 직접 화면에 입력하게 합니다.
- 법 해석(AI기본법 '이용자', 개인정보 보호법 종교단체 예외 등)은 "법률 자문이 아님"을 붙이고 단정하지 않습니다.
- 개인정보가 든 실제 사진·자료가 보이면 멈추고 5회차 원칙을 확인합니다.

### 확인 필요로 남긴 것
- 네이버 블로그 개설·'단체회원' 가입의 현재 화면 순서(조사하지 않음).
- 로그인 화면의 '로그인 상태 유지' 정확한 문구(화면 문구는 조금 다를 수 있음).
- 비공개 발행이 하루 발행 수 제한에 포함되는지. ('AI 활용 설정'은 2026-10-08 실측 결과 사진·영상마다 있는 스위치입니다.)
- ChatGPT Plus 가격의 부가세 포함 여부, OpenAI가 현재도 실사 아동 사진 편집을 일괄 거절하는지.
- 블로그 도우미 확장은 2026-10-08 강사 실측을 마쳤고, 2026-10-08~09에는 여행 스튜디오로 실제 사진·영상을 써서 글 3편을 목록부터 사람 발행까지 끝까지 확인했습니다(공통 문서 '실측 결과', 확장 0.5.1). 사진 설명이 안 들어가는 원인, 예약 발행, Chrome·Mac은 아직 남았습니다.
