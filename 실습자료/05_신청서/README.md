# 05_신청서 (5회차 실습용 · 모두 가상 데이터)

가상 선교사 사역 후원 신청서 8장(`신청서_01.docx` ~ `신청서_08.docx`)입니다. 모두 같은 표 양식이며, 이름·연락처·이메일·생년월일·소속·사역 국가/지역·사역 내용·후원 요청 사유 칸이 있습니다.

- 쓰는 곳: **5회차 Part 2 — 신청서 → 엑셀 표(DB)**
- 연락처는 모두 `010-0000-xxxx`, 이메일은 `@example.com` 형식의 가짜입니다.
- 일부 신청서에는 **빈칸**이나 **형식 오류**가 섞여 있고, **보안국가 신청서**도 한 장 있습니다. 어떤 것인지 찾아내고 표에 '확인 필요'로 표시하는 것이 실습의 일부입니다.
- 사용법: 폴더를 `실습공간/05회차/`로 복사한 뒤 복사본으로 실습하세요.
