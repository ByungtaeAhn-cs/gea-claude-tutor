# 인수인계 메모 만들기

지금 세션에서 한 일을 다음 세션(또는 다른 사람)이 바로 이어받을 수 있도록 메모로 정리합니다. 컨텍스트(AI가 한 번에 기억하는 대화 분량)가 가득 차기 전에, 또는 주제가 바뀔 때 쓰는 도구입니다.

## 순서

1. 이번 세션의 대화와 작업한 파일을 돌아보고 아래 형식으로 메모를 씁니다. 추측으로 채우지 말고, 모르는 칸은 "확인 필요"라고 적습니다.
2. 저장 위치를 정합니다.
   - 이 폴더에 `내_학습기록/` 폴더가 있으면 `내_학습기록/인수인계/` 아래에 저장합니다.
   - 없으면 현재 폴더의 `인수인계/` 아래에 저장합니다.
   - 파일 이름은 `YYYY-MM-DD_주제.md` 형식입니다. 주제는 사용자가 준 것($ARGUMENTS)을 쓰고, 없으면 작업 내용을 2~4단어로 요약해 씁니다.
3. 저장한 뒤 사용자에게 메모의 요약(3줄)과 파일 경로를 알려 줍니다.
4. 마지막으로 이어하는 방법을 안내합니다.
   - "새 세션을 열고(Windows **Ctrl+N**, Mac **Cmd+N**) 이렇게 말해 보세요: `(방금 저장한 파일 경로) 읽고 이어서 진행해줘`" — 괄호 자리에 실제 경로(예: `내_학습기록/인수인계/2026-10-05_소식지.md`)를 채워서 안내합니다.

## 메모 형식

```markdown
# 인수인계: (주제)
- 날짜: YYYY-MM-DD
- 작업 폴더: (경로)

## 1. 목표
(이 작업으로 이루려는 것 1~2줄)

## 2. 지금까지 한 일
- (완료한 일, 만든·고친 파일 경로 포함)

## 3. 정한 것 (결정 사항과 이유)
- (결정 — 이유)

## 4. 남은 일 (다음에 할 순서대로)
1. …

## 5. 주의사항
- (막혔던 점, 하지 말아야 할 것, 개인정보 관련 주의 등)

## 6. 다음 세션 첫 문장 (복붙용)
> (이 메모를 읽고 무엇부터 할지 한 문장)
```

## 지켜야 할 것

- 개인정보(실명·연락처·주민번호·계좌·보안국가 선교사 정보)는 메모에 옮겨 적지 않습니다. 필요하면 "○○ 파일 참조"처럼 위치만 적습니다.
- 메모는 한 화면(40줄 안팎)에 들어오게 짧게 씁니다.
