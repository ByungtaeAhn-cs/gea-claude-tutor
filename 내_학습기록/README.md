# 내_학습기록 — 튜터가 나의 진도를 기억하는 곳

튜터가 학습을 이어 가기 위해 이 폴더에 기록을 저장합니다.

| 파일·폴더 | 내용 |
|-----------|------|
| `학습자_프로필.md` | 호칭, 소속 단체, 하는 일, AI 사용 경험, 해결하고 싶은 일 (1회차에서 작성) |
| `진도.md` | 어느 회차·어느 Part까지 했는지 (Part가 끝날 때마다 갱신) |
| `내_프로젝트.md` | 2회차에서 고른 관통 프로젝트 카드 |
| `인수인계/` | 세션을 나눠 이어 할 때 남기는 인수인계 메모 |
| `수료카드.md` | 10회차에서 만드는 수료 카드 |

- 처음에는 이 안내 파일만 있습니다. 튜터가 필요할 때 파일을 만듭니다.
- 이 폴더의 내용은 **git에 올라가지 않습니다**(이 안내 파일만 예외). 튜터를 업데이트해도 내 기록은 지워지지 않습니다.
- 다음에 이어서 할 때는 튜터 폴더를 열고 "이어서 하자"라고 말하면 튜터가 여기 기록을 읽고 이어 갑니다.
