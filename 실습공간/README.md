# 실습공간 — 여기서 실습합니다

- 회차별 실습은 `실습자료/`의 원본을 이 폴더로 **복사한 뒤** 복사본으로 합니다. 예: `실습공간/06회차/`
- 실전 과제 결과물은 `실습공간/과제/N회차/`에, 관통 프로젝트는 `실습공간/과제/내프로젝트/`에 둡니다.
- 이 폴더의 내용은 **git에 올라가지 않습니다**(이 안내 파일만 예외). 튜터를 최신 버전으로 업데이트해도 여기 만든 파일은 그대로 남습니다.
- 실제 업무 파일을 가져올 때는 먼저 5회차의 개인정보 원칙을 떠올리세요. 개인정보가 든 원본은 되도록 여기 넣지 말고, 필요한 열만 남긴 'AI용 사본'을 쓰세요.
- 일상 실습 ①(단체 블로그)을 관통 프로젝트로 하면 `과제/내프로젝트/`가 블로그 프로젝트 폴더가 됩니다. 9회차부터는 이 폴더를 **Select folder**로 직접 열어 작업합니다. 여행 스튜디오는 `실습공간/여행스튜디오/`에 만듭니다.
