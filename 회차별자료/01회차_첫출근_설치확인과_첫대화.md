## Part 1: 설치 점검과 튜터 폴더 열기 (15분)

### 1.1 폰 속 AI, 내 폴더 속 AI

🧩 **비유**: 폰의 ChatGPT는 **전화로만 상담하는 외부 컨설턴트**입니다. 자료를 보여 주려면 내가 일일이 복사해 붙여야 하고, 조언을 들은 뒤 실제 일은 내가 합니다. Code 탭의 Claude는 **내 사무실에 출근한 신입 동료**입니다. 내가 열어 준 서랍(폴더)의 서류를 직접 보고, 허락하면 직접 정리합니다.

**설명**: Claude 데스크탑 앱의 **Code** 탭에서는 내 컴퓨터의 폴더 하나를 골라 그 안에서 Claude와 일합니다. Claude는 폴더 안 파일을 읽고, 새 파일을 만들고, 필요한 프로그램 명령(컴퓨터에 내리는 작업 지시)을 실행할 수 있습니다. 무엇을 어디까지 스스로 해도 되는지는 **권한 모드**(Part 2)로 선생님이 정합니다.

**우리 단체 예시**: 엘리온에듀학원 선생님의 콘텐츠 폴더에 `빛_활동지_최종.docx`, `빛_활동지_최종2.docx`, `빛_활동지_진짜최종.docx`가 섞여 있다고 해 보겠습니다. 폰 AI에게는 파일 이름을 하나하나 적어 보내야 하지만, Code 탭의 Claude에게는 "이 폴더에서 최신본 후보와 중복 파일을 찾아줘" 한 줄이면 됩니다.

💭 **확인 질문**: 둘 중 "파일을 직접 옮길 수 있는" 쪽은 어느 쪽이고, 그 대신 선생님이 챙겨야 할 것은 무엇일까요?

### 1.2 실습: Code 탭 확인 → 튜터 받기 → 튜터 폴더 열기 → 환경 점검

🎯 **목표**: 튜터 폴더를 Code 탭에서 열고, Git·Python이 준비됐는지 Claude가 확인하게 합니다.

🛠 **준비**
- 로그인된 Claude 데스크탑 앱, 인터넷
- 튜터 주소: `https://github.com/ByungtaeAhn-cs/gea-claude-tutor`
- 용어 두 개: **레포**(저장소 — 인터넷에 올려 둔 폴더), **Git**(파일의 세이브 포인트를 남기는 프로그램, 4회차에서 자세히)

👣 **단계**

**① Code 탭이 열리는지 확인** (모두 먼저)
1. 앱 화면 위 가운데의 **Chat / Cowork / Code** 중 **Code**를 누릅니다.
2. **Select folder**(폴더 선택) 버튼과 입력창이 보이면 통과입니다.
3. "업그레이드(Upgrade)" 안내가 나오면 **결제 버튼은 누르지 마세요.** 단체 팀 초대를 아직 수락하지 않은 상태입니다.
   - 메일함(스팸함 포함)에서 Claude 또는 Anthropic 초대 메일 → 초대 수락 버튼 → **같은 이메일**로 로그인
   - 앱을 **완전히 종료**합니다. Windows는 창을 닫은 뒤 작업 표시줄 오른쪽 아래 숨은 아이콘(^) 속 Claude 아이콘까지 종료, Mac은 **Cmd+Q**.
   - 앱을 다시 실행하고 **Code** 탭을 누릅니다.
   - 초대 메일이 아예 없으면 손을 들어 강사에게 알려 주세요. 혼자 하실 때는 단체 담당자에게 초대 메일을 다시 보내 달라고 요청하세요.

**② 튜터 받기** — (B) 딸깍 방법을 권장합니다. 안 되면 (A)로 하세요.

(B) 딸깍: Claude에게 받아 달라고 하기
1. 새 세션(한 업무를 위한 대화 묶음)을 엽니다: **Ctrl+N**(Mac **Cmd+N**). 환경이 **Local**(내 컴퓨터)인지 확인합니다.
2. **Select folder** → **문서**(Documents) 폴더를 고릅니다. 이 폴더를 신뢰(Trust)할지 묻는 창이 뜨면 신뢰를 눌러도 괜찮습니다(튜터를 받아 오는 데만 씁니다).
3. 전송 버튼 옆 권한 모드 선택기가 **Manual**인지 확인합니다(Part 2에서 자세히).
4. 입력창에 붙여 넣고 Enter:
   ```
   https://github.com/ByungtaeAhn-cs/gea-claude-tutor 를 이 폴더에 받아줘
   ```
5. Claude가 `git clone https://github.com/...` 같은 **명령을 실행하겠다고 물어봅니다.** 명령 안에 위 주소가 들어 있는지 보고 허용합니다(화면 문구는 조금 다를 수 있습니다). 공개 자료라 GitHub 로그인은 필요 없습니다.
6. "문서 폴더에 `gea-claude-tutor` 폴더가 생겼습니다" 같은 답이 나오면 완료입니다. 방금 누른 것이 선생님의 **첫 승인**입니다.

(A) 직접 받기: ZIP 파일
1. 브라우저로 위 주소 접속 → 초록색 **Code** 버튼(앱의 Code 탭과 이름만 같습니다) → **Download ZIP**(압축 파일로 받기).
2. 받은 ZIP의 압축을 풉니다. Windows는 파일 우클릭 → **모두 압축 풀기**, Mac은 더블클릭.
3. 풀린 폴더를 **문서** 폴더로 옮깁니다. 이름이 `gea-claude-tutor-main`처럼 뒤에 글자가 붙어 있어도 괜찮습니다.
4. 폴더를 열었는데 같은 이름 폴더가 또 들어 있으면, `README.md`가 보이는 **안쪽 폴더**가 튜터 폴더입니다.

**③ 튜터 폴더 열기**
1. 새 세션(**Ctrl+N** / **Cmd+N**) → 환경 **Local** → **Select folder** → 문서 안의 `gea-claude-tutor` 폴더.
   - 💡 처음 폴더를 열면 이 폴더를 신뢰할지(Trust) 묻는 창이 뜰 수 있습니다. 이 튜터 폴더는 신뢰를 눌러 주세요. 그래야 튜터가 진도를 저장할 때마다 승인 창이 뜨지 않습니다. (화면 문구는 조금 다를 수 있습니다.)
2. 권한 모드가 **Manual**인지 확인합니다.
3. 입력창에:
   ```
   1회차 시작
   ```
4. 튜터 답의 첫 줄에 `🗺️ 1회차 · Part 1/4 · …` 같은 **현재 위치**가 보이면 튜터가 켜진 것입니다.

**④ 환경 점검** (여기부터는 튜터가 안내합니다)
1. 튜터가 Git·Python 확인을 제안합니다. 제안이 없으면 이렇게 입력하세요.
   ```
   Git이랑 Python이 설치돼 있는지 확인해줘
   ```
2. Claude가 `git --version`, `python --version`(Windows는 `py --version`도, Mac은 `python3 --version`) 같은 명령을 실행하겠다고 물어봅니다 → 허용.
3. 결과를 "Git ✅ / Python ✅"처럼 버전 번호와 함께 알려 줍니다.
4. **Python이 없다고 나오면**(Windows에서 흔합니다) 이렇게 입력합니다.
   ```
   파이썬 설치해줘
   ```
   - Windows: Claude가 **winget**(Windows에 들어 있는 프로그램 설치 도구)으로 설치 명령을 실행하겠다고 물어봅니다 → 무엇을 설치하는지 확인하고 허용. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 같은 창이 뜨면 **예**.
   - Mac: 보통 Git을 설치할 때 함께 들어 있어 할 일이 없습니다.
5. 설치가 끝나면 한 번 더 확인합니다.
   ```
   파이썬이 제대로 설치됐는지 다시 확인해줘
   ```

> 💡 Python은 Claude가 엑셀·워드·PPT 파일을 만들고 계산할 때 쓰는 도구입니다(6·7회차). 오늘 폴더 정리에는 없어도 되지만, 오늘 준비해 두면 편합니다.

## Part 2: 화면 투어와 권한 모드 (15분)

### 2.1 화면 지도 — 신입 동료의 책상 배치

🧩 **비유**: 새 사무실에 출근하면 전화기·결재함·비상정지 스위치 위치부터 익힙니다. 앱 화면도 몇 군데만 알면 충분합니다.

**설명**: 오늘 알아 둘 곳은 아래 표가 전부입니다. 영어 이름은 화면에 보이는 그대로 적었습니다.

| 위치 | 이름 | 하는 일 | 오늘은 |
|------|------|---------|--------|
| 화면 위 가운데 | **Chat / Cowork / Code** 탭 | Chat은 우리가 알던 대화창, Code는 내 폴더 안에서 일하는 곳 | Code만 씁니다(Cowork는 이 과정에서 쓰지 않음) |
| 왼쪽 | 사이드바 | 세션 목록 | 보기만 |
| 아래 | 입력창 | 일을 맡기는 곳. `@파일이름`으로 파일을 콕 집어 말할 수 있음 | 사용 |
| 입력창 옆 | **+** 버튼 | 파일 첨부, **Slash commands**(/ 명령 목록), **Connectors**(외부 서비스 연결), **Plugins**(도구 묶음) | 눌러만 보기(8회차) |
| 전송 버튼 옆 | 모델 선택 | 어떤 Claude 두뇌를 쓸지 | **기본값 그대로** |
| 전송 버튼 옆 | 권한 모드 선택기 | Claude가 스스로 해도 되는 범위 | **Manual** |
| 모델 선택 옆 | 사용량 링 | 이 세션의 컨텍스트(AI가 한 번에 기억하며 보는 양) 사용량 + 요금제 사용량 | 눌러만 보기(3회차) |
| 파일이 바뀐 뒤 | `+12 -1` 같은 표시 | 누르면 **diff**(바뀐 부분 비교) 화면 | Part 3에서 |
| 일하는 중 | 정지 버튼 / **Esc** | 즉시 멈춤 | 연습 |

- `+12 -1`은 "12줄 더하고 1줄 뺐다"는 뜻입니다. Word의 '변경 내용 추적'처럼 무엇이 바뀌었는지 보여 줍니다. 다만 실습 폴더(`실습공간/`)처럼 기록 관리에서 빠진 폴더에서는 이 표시가 안 보일 수 있습니다. 그럴 땐 **Manual** 모드의 승인 창에서 바뀔 내용을 확인하면 됩니다.
- Claude가 일하는 중에도 고칠 말을 입력하고 Enter를 누르면 반영합니다.
- 단축키 목록은 **Ctrl+/**(Mac **Cmd+/**)로 볼 수 있습니다.

**우리 단체 예시**: 다니엘칼리지 간사님이 학부모 공지문을 Claude에게 다듬게 했다면, `+5 -3` 표시를 눌러 어느 문장이 바뀌었는지 확인한 뒤 수락합니다. 공지가 학부모님께 나가기 전에 사람이 확인하는 자리입니다.

💭 **확인 질문**: Claude가 엉뚱한 방향으로 일하고 있을 때, 가장 먼저 누를 키는 무엇일까요?

### 2.2 권한 모드 — 결재 방식 정하기

🧩 **비유**: 신입에게 첫날부터 법인 도장을 통째로 맡기지 않습니다. 처음엔 하나하나 결재를 받게 하고, 믿음이 쌓이면 "문서 수정은 알아서 하고, 그 밖의 일만 물어봐"로 넓힙니다.

**설명**: 권한 모드는 전송 버튼 옆 선택기에서 고릅니다.

| 모드 | 하는 일 | 결재 비유 | 이 과정에서 |
|------|---------|-----------|-------------|
| **Manual** | 파일 수정·명령 실행 전에 매번 물어봄. 바뀐 내용(diff)을 보고 **Accept**(수락)/**Reject**(거절) | 건마다 결재 | **1회차 기본** |
| **Accept edits** | 파일 수정은 자동 승인, 그 밖의 명령은 물어봄 | 문서 수정은 전결, 나머지는 결재 | 익숙해지면 |
| **Plan** | 파일은 고치지 않고 계획만 제안. 이 세션에만 적용 | 기획안만 먼저 | 큰 일을 맡기기 전 |
| **Auto** | 백그라운드 안전 검사와 함께 자동 실행. 사용 가능할 때만 보임 | 내부 감사가 붙은 위임 | 안 보여도 정상 |
| **Bypass permissions** | 확인 없이 모두 실행 | 도장을 통째로 맡김 | **쓰지 않습니다** |

- 단축키: **Ctrl+Shift+M**(Mac **Cmd+Shift+M**).
- 고른 모드는 **폴더별로 기억**됩니다. 튜터 폴더에서 Manual로 해 두면 다음에도 Manual입니다.
- 인터넷 자료에 Ask permissions / Auto accept edits / Plan mode라고 나오면 각각 Manual / Accept edits / Plan의 예전 이름입니다.
- 권장 순서: 처음엔 **Manual**로 "승인하는 감각"을 익히고 → 익숙해지면 **Accept edits**. **Plan**은 언제든 큰 일 전에.

**우리 단체 예시**: 다음세대교육연합의 법인 서류(정관·이사회 회의록) 폴더처럼 중요한 자료에서는 Manual을 유지합니다. 반면 소식지 초안을 여러 번 고쳐 쓰는 연습 폴더라면 Accept edits가 편합니다.

💭 **확인 질문**: 후원자 명단이 든 폴더에서 일할 때 **Bypass permissions**를 쓰면 안 되는 이유는 무엇일까요?

### 2.3 실습: 화면 투어 (5분)

🎯 **목표**: 권한 모드를 직접 바꿔 보고, **Esc**로 멈춘 뒤 다시 지시하는 연습을 합니다.

🛠 **준비**: 튜터 폴더를 연 지금 세션 그대로.

👣 **단계**
1. 권한 모드 선택기를 눌러 목록을 봅니다(**Auto**는 없을 수 있습니다) → **Plan** 선택 → 다시 **Manual** 선택.
2. **Ctrl+Shift+M**(Mac **Cmd+Shift+M**)을 눌러 무엇이 바뀌는지 봅니다 → **Manual**로 돌려놓습니다.
3. 모델 선택 옆 **사용량 링**을 눌러 보고 닫습니다. 숫자의 뜻은 3회차에서 배웁니다.
4. **+** 버튼을 눌러 메뉴 이름을 확인하고 닫습니다. 입력창에 `/`만 입력해 목록을 본 뒤 지웁니다.
5. 멈추기 연습 — 아래를 입력하고, Claude가 일을 시작하면 바로 **Esc**(또는 정지 버튼)를 누릅니다.
   ```
   이 튜터 폴더의 파일을 하나씩 모두 열어서 자세히 설명해줘
   ```
6. 멈춘 것을 확인한 뒤 방향을 바꿔 줍니다.
   ```
   그만하고, 이 폴더에 있는 큰 폴더 이름만 한 줄씩 알려줘
   ```
7. 사이드바에서 세션 목록을 봅니다. (B)로 튜터를 받았다면 '문서' 폴더에서 연 세션도 목록에 있을 것입니다.

✅ **이렇게 되면 성공**
- 권한 모드가 **Manual**로 맞춰져 있다
- **Esc**로 멈추고, 새 지시로 방향을 바꿔 봤다

🆘 **막히면**
- 선택기가 안 보이면: 전송 버튼 바로 옆을 다시 보거나 **Ctrl+Shift+M**을 눌러 보세요.
- **Esc**가 안 먹으면: 정지 버튼을 누릅니다.
- 튜터가 5번 요청을 진짜로 끝까지 하려 해도 괜찮습니다. 멈추는 연습이 목적입니다.

## Part 3: 첫 실습 — 뒤죽박죽 폴더 정리 (25분)

### 3.1 계획 먼저, 실행은 승인 후

🧩 **비유**: 좋은 이삿짐 업체는 짐을 옮기기 전에 **배치도**부터 보여 줍니다. 확인하고 고친 뒤에야 옮기고, 상자마다 "이거 여기 둘까요?"라고 묻습니다. **Plan** 모드가 배치도, **Manual** 승인이 상자마다 묻는 것입니다.

**설명**: **Plan** 모드에서 Claude는 파일을 건드리지 않고 계획만 보여 줍니다. 계획이 마음에 들지 않으면 말로 고칩니다. 확정되면 **Manual**로 바꾸고 실행을 맡기는데, 이때 하나하나 승인하며 지켜봅니다. 정리할 때는 지우지 말고 옮기는 것이 기본입니다.

**우리 단체 예시**: SHINE행복한학교의 홍보 영상 기획 폴더에 기획서·대본·콘티·레퍼런스 메모가 섞여 있다면, 먼저 "제작 단계별로 정리하는 계획부터 보여줘"라고 합니다. 계획표를 보며 "레퍼런스는 따로 빼 줘"처럼 고친 뒤 실행합니다.

💭 **확인 질문**: Plan 모드에서 Claude가 보여 준 계획이 마음에 들지 않으면 어떻게 하면 될까요?

### 3.2 실습: 뒤죽박죽 폴더 정리하기

📂 **실습 데이터 선택**: 튜터가 먼저 묻습니다 — ① 제공된 가상 샘플(기본, 오늘 권장) ② 내 업무 양식을 본뜬 가상 데이터 ③ 내 실제 파일(개인정보 점검 먼저 — 실전 과제에서 권장).

🎯 **목표**: 가상 파일 20개 내외가 섞인 폴더를 Claude가 **직접 보고 → 계획하고 → 승인받아 정리하고 → 기록까지** 남기게 합니다.

🛠 **준비**
- 튜터 폴더 세션, 권한 모드 **Manual**
- 원본: `실습자료/01_뒤죽박죽폴더/` — 회의록(txt/docx), `IMG_날짜` 이름의 사진, 소식지 초안, `영수증목록.csv`, `행사안내.docx`, 메모, 중복 파일 등(모두 가상)

👣 **단계**
1. **복사** — 입력하면 Claude가 복사 명령을 실행하겠다고 물어봅니다 → 허용.
   ```
   실습자료/01_뒤죽박죽폴더 안의 파일을 모두 실습공간/01회차/ 폴더로 복사해줘. 원본은 건드리지 마.
   ```
2. **파악** — 폴더를 직접 보게 합니다.
   ```

   ```
3. **계획** — 권한 모드를 **Plan**으로 바꾸고 입력합니다.
   ```
   실습공간/01회차 폴더를 종류별로 정리하는 계획을 먼저 보여줘. 어떤 폴더를 만들고 어떤 파일을 어디로 옮길지 표로 보여줘.
   ```
4. **계획 고치기** — 한 번 이상 고쳐 봅니다.
   ```
   사진은 파일 이름에 있는 날짜 기준으로 날짜별 폴더로 나눠 줘. 중복 파일은 지우지 말고 '중복_확인필요' 폴더로 옮겨 줘.
   ```
5. **실행** — 권한 모드를 **Manual**로 바꾸고 입력합니다.
   ```
   좋아. 수정한 계획대로 실행해줘.
   ```
   - 승인 창이 여러 번 뜹니다. 무엇을 어디로 옮기는지 읽고 허용하세요. 이상하면 거절한 뒤 이유를 입력하면 됩니다.
   - 화면에 실행 방식을 고르는 선택지가 나오면, 하나하나 승인하는 쪽을 고르세요(화면 문구는 조금 다를 수 있습니다).
6. **검산** — 사라진 파일이 없는지 확인합니다.
   ```
   정리 전과 후의 파일 개수가 같은지 세어서 비교해줘. 없어진 파일이 있으면 알려줘.
   ```
7. **기록** — 결과를 파일로 남깁니다.
   ```
   정리 결과를 실습공간/01회차/정리안내.md로 남겨줘. 만든 폴더, 옮긴 파일 목록, 중복 의심 파일, 사람이 확인해야 할 것을 적어줘.
   ```
   - **Manual**에서는 파일을 만들기 전에 바뀔 내용(**diff**)을 보여 주며 묻습니다 → 읽어 보고 **Accept**. 만든 뒤에는 `+NN -0` 같은 표시를 눌러 다시 볼 수 있습니다.
8. **쉽게 풀기** — 카드 한 장을 써 봅니다.
   ```
   방금 한 일을 초등학생도 알게 설명해줘.
   ```
9. **돌아보기** — 폰 AI였다면 무엇이 달랐을지 비교해 봅니다.

| 통제 | — | 권한 모드와 승인으로 내가 결재 |

✅ **이렇게 되면 성공**

| 진도 저장 때 승인 창 | 튜터가 진도·프로필을 저장할 때마다 승인 창이 뜸 | 폴더 신뢰(Trust)를 안 한 경우일 수 있음 → 튜터 폴더를 다시 열 때 신뢰를 누르게 함. 그 전까지는 저장 승인 창을 허용하면 됨 |
| Mac Python | `python` 명령이 없음 | Mac은 `python3`로 확인. 버전이 나오면 준비 완료 |

### 퀴즈 정답과 해설

1. **① Manual**. Accept edits는 파일 수정은 자동, 그 밖의 명령만 묻습니다. Auto는 안전 검사와 함께 자동 실행, Bypass permissions는 확인 없이 모두 실행하므로 이 과정에서 쓰지 않습니다.
2. **X**. Plan은 파일을 고치지 않고 계획만 제안하며, 그 세션에만 적용됩니다. 실행하려면 Manual(또는 Accept edits)로 바꿉니다.
3. **②**. Esc 또는 정지 버튼으로 멈추고 바른 지시를 입력합니다. 이미 바뀐 것은 "방금 한 것 원래대로 되돌려줘"로 되돌립니다.
4. **X**. 단체 팀 초대를 수락하고 같은 이메일로 로그인한 뒤 앱을 완전히 종료했다가 다시 켭니다. 결제하면 개인 결제가 되어 버립니다.
5. **모범 답안 요소**: 폰 AI는 파일 목록을 내가 붙여 넣어야 하고, 실제 옮기는 일도 내가 한다. Code 탭은 폴더를 직접 보고 계획을 세우며, 내가 승인하면 직접 옮기고 기록까지 남긴다. 핵심어 '직접 본다', '직접 한다', '내가 승인한다' 중 둘 이상이면 통과로 봅니다. 부족하면 3.2의 돌아보기 표를 힌트로 줍니다.

### 실전 과제 검수 기준

- [ ] 원본이 아니라 `실습공간/과제/01회차/`의 **복사본**으로 했다
- [ ] 파일 내용을 열기 전에 **파일 이름 목록으로 개인정보 점검**을 먼저 했다
- [ ] 폴더 설명(종류·개수)을 받았다
- [ ] Plan 모드로 계획을 받고 **최소 1회 고쳤다**
- [ ] 실행했다면 정리 전후 파일 개수가 같고, 지운 파일이 없다(중복은 옮기기)
- [ ] `정리계획.md`(또는 `정리안내.md`)가 저장됐다
- [ ] "폰 AI와 다른 점" 소감을 한 줄로 말할 수 있다

검수할 때는 정답을 먼저 말하지 말고 "계획을 한 번 고쳐 보셨나요?", "파일 개수는 확인하셨나요?"처럼 질문으로 이끕니다.

### 안전·개인정보 주의

- 실습자료는 모두 가상입니다. 실제 업무 폴더는 **복사본**으로, **개인정보가 없는 것만** 씁니다. 학습자가 개인정보가 든 폴더를 쓰려 하면 5회차 원칙을 짧게 상기시킵니다: 필요한 것만, 가명 먼저, 민감정보와 보안국가 선교사 정보는 넣지 않기.
- 파일 이름 목록에서 개인정보가 의심되면 **내용을 열기 전에** 멈추고, 학습자가 파일 탐색기로 직접 과제 폴더 밖으로 옮기게 합니다. AI가 읽은 내용은 이미 전송된 것이므로 '열기 전 점검'이 핵심입니다.
- 권한 모드는 오늘 **Manual**. **Bypass permissions**는 권하지 않습니다.
- 정리할 때는 지우지 말고 옮깁니다. 삭제가 필요해 보이면 '확인필요' 폴더로 옮기고 사람이 판단하게 합니다.
- 설치 명령은 공식 도구(winget, git)와 알려진 주소만 승인하도록 안내합니다. 출처를 모르는 설치 요청은 거절해도 된다고 알려 줍니다.
- 데스크탑 앱은 대화 기록을 내 PC에 남깁니다. 공용 PC라면 주의하도록 한 줄 알려 줍니다.
- 개인 Pro 사용자는 설정 → 개인정보(Privacy) → 'Help improve Claude'를 끄는 방법이 있다는 것만 알리고, 자세한 내용은 5회차로 넘깁니다.

### 강사가 강의 당일 함께 진행할 때의 팁

**진행 속도 맞추기**
- 강사가 단계 번호를 불러 줍니다("②-(B) 5번까지 오세요"). 다 된 분은 노트북 위에 초록 포스트잇, 막힌 분은 빨간 포스트잇을 붙입니다(강사 준비물). 포스트잇이 없으면 손을 들어도 됩니다.
- 학습자가 튜터에게 "강사님과 같이 하는 중이야. 한 단계씩만 안내해줘"라고 입력하면, 튜터는 **한 단계씩만** 안내하고 먼저 앞서가지 않습니다. 다음 Part는 학습자가 "다음"이라고 할 때만 넘어갑니다.
- Part 3의 Plan → Manual 전환은 강사 화면으로 한 번 먼저 보여 주고 따라 하게 하면 빠릅니다.
- 2회차가 바로 이어지므로 Part 4(프로필 저장)는 쉬는 시간 전에 꼭 마칩니다.

**막힌 사람 대응**
- **3분 규칙**: 3분 넘게 막히면 강사 메모('주차장')에 이름과 증상을 적고, 옆 사람 화면으로 따라 보며 진행한 뒤 쉬는 시간에 해결합니다.
- 빨리 끝난 🌳 학습자에게 옆자리 도우미를 부탁합니다. 이때도 대신 눌러 주지 말고 말로 안내하게 합니다.
- **Code 탭이 잠긴 분**: 옆 사람과 짝을 지어 화면을 같이 보며 참여하고, 초대가 해결되면 Part 1 ①부터 따라잡습니다. 당일 해결이 안 되면 집에서 1회차를 튜터와 다시 하도록 안내합니다.
- (B)가 여러 명 동시에 막히면(네트워크·Git 문제) 망설이지 말고 (A) ZIP으로 전환합니다.
- 튜터에게 "도움 — (증상)"이라고 입력하게 하면, 튜터가 위 '자주 막히는 지점' 표로 진단합니다.
- Windows '문서' 폴더 경로에 OneDrive가 들어 있으면 강사에게 알리게 합니다. 4회차에서 다룰 '동기화 폴더 안에 Git 폴더를 두지 않기' 원칙과 관련이 있습니다.
