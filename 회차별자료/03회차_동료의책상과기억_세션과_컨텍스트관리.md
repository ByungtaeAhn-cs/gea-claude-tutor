## Part 1: 컨텍스트 = 동료의 책상 (15분)

### 1.1 컨텍스트는 동료의 책상 위입니다

**🧩 비유**
신입 동료의 책상을 떠올려 보세요. 선생님이 한 말, 건네준 서류, 동료가 찾아본 자료가 모두 책상 위에 펼쳐집니다. 책상은 넓지만 끝이 있습니다.

**설명**
**컨텍스트**(AI가 한 번에 기억하며 보는 대화·자료의 양)가 바로 이 책상 위입니다. 선생님의 말뿐 아니라 Claude가 읽은 파일, 실행한 명령의 결과도 모두 책상에 올라갑니다. 책상이 가득 차면 Claude는 **앞부분을 요약 메모 한 장으로 바꾸고 원본은 치운 뒤** 계속 일합니다(자동 요약). 이때 세부 내용이 사라질 수 있고, 책상이 너무 어지러우면 앞에서 한 부탁을 놓치거나 실수가 늘 수 있습니다.

**우리 단체 예시**
미션펀드 간사님이 한 대화에서 선교사 신청서 8개를 읽히고, 이어서 분기 소식 글을 쓰고, 또 정산 수식까지 물었다고 해 봅시다. 책상에는 신청서 내용이 잔뜩 쌓여 소식 글을 쓸 자리가 좁아집니다. 처음에 말한 "기도제목은 번호를 붙여 줘" 같은 부탁이 요약 과정에서 빠질 수도 있습니다.

**💭 확인 질문**: 책상이 가득 찼을 때 Claude는 무엇을 하고, 그때 무엇을 잃을 수 있을까요?

### 1.2 세션은 업무 하나를 위한 새 서류철입니다

**🧩 비유**
일 잘하는 사무실은 업무마다 서류철을 따로 만듭니다. '10월 체험학습 공지' 서류철을 펼치면 그 업무 서류만 책상에 올라옵니다.

**설명**
**세션**(Code 탭의 대화 하나)은 서류철 하나입니다. 세션마다 책상(컨텍스트)이 따로 있어서, 새 세션을 열면 깨끗한 책상에서 시작합니다. 지난 세션은 지워지지 않고 **사이드바**(세션 목록)에 남아 있어 언제든 다시 열 수 있습니다. 데스크탑 앱은 대화 기록을 내 PC에 남깁니다.

**우리 단체 예시**
사실 이 튜터가 이미 그렇게 일하고 있습니다. 오늘 새 세션을 열었는데도 튜터가 선생님의 진도를 아는 이유는, 책상이 아니라 **서랍 속 파일**(`내_학습기록/진도.md`)에 적어 두었기 때문입니다. **깨끗한 새 책상 + 서랍 속 메모**, 이것이 오늘 배울 핵심 구조입니다.

**💭 확인 질문**: 새 세션을 열면 이전 세션의 대화는 지워질까요, 남아 있을까요?

### 1.3 해 보기: 사용량 링으로 책상 상태 보기

**🎯 목표**: 지금 세션의 책상이 얼마나 찼는지 직접 확인합니다.

**🛠 준비**: 지금 튜터와 대화 중인 이 세션이면 됩니다.

**👣 단계**
1. 전송 버튼 근처, **모델 선택기 옆의 사용량 링**(작은 동그라미)을 누릅니다.
2. 두 가지를 찾아봅니다: **이 세션의 컨텍스트 사용량**(책상이 찬 정도)과 **요금제 사용량**(이번 기간에 쓴 양).
3. 튜터에게 "책상이 대략 얼마나 찼는지"를 말해 보세요.

**✅ 이렇게 되면 성공**: '컨텍스트 사용량'과 '요금제 사용량'이 서로 다른 것임을 말할 수 있습니다.

**🆘 막히면**: 링이 안 보이면 Claude에게 "컨텍스트 사용량은 어디서 봐?"라고 물어보세요. 모양이나 위치는 앱 버전에 따라 조금 다를 수 있습니다.

### 1.4 ChatGPT에서 하던 습관, 왜 문제일까요?

**🧩 비유**
모든 업무 서류를 서류철 하나에 몽땅 끼워 두는 사무실을 상상해 보세요. 넣을 땐 편하지만, 찾을 때와 넘겨줄 때 곤란해집니다.

**설명**
폰의 ChatGPT에서는 대화창 하나에 이것저것 묻는 일이 흔합니다. Claude Code는 파일을 읽고 명령을 실행하기 때문에 책상이 훨씬 빨리 찹니다. 그래서 습관을 바꾸면 효과가 큽니다.

| 예전 습관 | 생기는 문제 | 바꿀 습관 |
|---|---|---|
| 대화창 하나에 모든 걸 묻기 | 앞 업무가 뒤 업무에 섞이고, "아까 그거"가 무엇인지 헷갈림 | 업무마다 새 세션 |
| 대화창 이름 없이 쌓아 두기 | 나중에 찾을 수 없음 | 세션 이름 짓기 |
| 잘 안 되면 계속 고쳐 달라기 | 실패한 시도가 책상에 쌓여 더 헷갈림 | 두 번 안 되면 새로 시작 |
| 다음 날 처음부터 다시 설명 | 시간 낭비, 빠뜨리는 내용 생김 | 인수인계 메모 |
| 매번 "존댓말로, ○○ 금지" 반복 | 한 번 빠뜨린 날 사고 | CLAUDE.md에 한 번 적기 |

**우리 단체 예시**
SHINE행복한학교 간사님이 '홍보 영상 기획' 대화창에서 갑자기 "학부모 설문 문항도 만들어줘"라고 하면, 설문에 영상 기획 말투가 섞일 수 있습니다. 나중에 설문을 찾으려면 긴 영상 대화를 뒤져야 합니다.

**💭 확인 질문**: 선생님이 폰 AI에서 가장 자주 하던 습관은 위 표의 어느 줄에 가깝나요?

## Part 2: 세션 관리 5습관 (20분)

### 2.1 다섯 가지 습관

**🧩 비유**
서류철 관리 요령 다섯 가지입니다. 업무마다 서류철을 만들고, 표지에 이름을 쓰고, 주제가 바뀌면 새 서류철을 꺼내고, 두꺼워지면 요약본만 남기고, 엉망이 되면 새 서류철에 깨끗이 다시 씁니다.

**설명**

| # | 습관 | 이렇게 합니다 | 왜 |
|---|---|---|---|
| ① | **1업무 1세션** | 업무 하나에 세션 하나 | 책상에 그 업무 서류만 올라감 |
| ② | **세션 이름 짓기** | 세션 위쪽 도구 모음의 제목을 눌러 이름 변경. 또는 "이 세션 이름을 ○○로 바꿔줘" | 사이드바에서 바로 찾음 |
| ③ | **주제가 바뀌면 새 세션** | **Ctrl+N**(Mac **Cmd+N**) | 업무끼리 섞이지 않음 |
| ④ | **길어지면 `/compact`** | `/compact 결정 사항과 남은 일 위주로`처럼 남길 것을 뒤에 적기 | 자동 요약을 기다리지 않고, 무엇을 남길지 내가 정함 |
| ⑤ | **두 번 고쳐도 안 되면 새로** | **Esc**로 멈추고 → 배운 점을 담은 더 나은 지시로 새 세션에서 다시 | 실패한 시도가 책상을 어지럽힘 |

세션 이름은 `단체_업무_날짜` 규칙을 추천합니다. 예: `미션펀드_가을소식_1005`, `교진추_과학교과서분석_1007`.

**우리 단체 예시**
교과서진화론개정추진회(교진추) 간사님이 교과서 인용 표를 만드는데 쪽수가 두 번이나 틀렸다면, 세 번째로 "또 틀렸어"라고 하기보다 새로 시작하는 편이 빠릅니다. "지금까지 배운 점을 반영해서 새 세션에 쓸 더 나은 지시문을 만들어줘"라고 한 뒤, 그 지시문을 새 세션에 붙여 넣으세요.

**💭 확인 질문**: ④ `/compact`와 ③ 새 세션은 각각 언제 쓰는 게 좋을까요?

### 2.2 덤: 곁가지 질문은 사이드 챗, 여러 업무는 세션 여러 개

**🧩 비유**
일하다가 옆자리 동료에게 "이 단어 뜻이 뭐였지?" 하고 잠깐 묻는 것과 같습니다. 서류철에는 아무것도 끼우지 않습니다.

**설명**
**사이드 챗**은 **Ctrl+;**(Mac **Cmd+;**)을 누르거나 입력창에 `/btw`를 쓰면 열립니다. 본 대화 내용을 읽고 답하지만, 본 대화에는 아무것도 더하지 않습니다. 사이드 챗은 앱에 저장되지 않으니, 남겨야 할 답은 본 대화로 옮기세요. 업무가 여러 개면 세션을 여러 개 열어 두고 사이드바나 **Ctrl+Tab**으로 오가면 됩니다.

**우리 단체 예시**
엘리온에듀학원 간사님이 STR '빛' 활동지를 만들다가 "광합성을 초등 3학년 말로 한 줄로 하면?"이 궁금할 때가 있습니다. 사이드 챗으로 물으면 활동지 대화는 깔끔하게 유지됩니다.

**💭 확인 질문**: 사이드 챗에서 얻은 좋은 문장을 나중에도 쓰고 싶다면 어떻게 해야 할까요?

**지금 해 보기**: **Ctrl+;**(Mac **Cmd+;**)로 사이드 챗을 열고 아래처럼 물은 뒤 닫아 보세요.

```
세션과 컨텍스트의 차이를 초등학생도 알게 한 줄로 말해줘.
```

### 2.3 실습: '뒤섞인 세션' 체험하고 나누기

**🎯 목표**: 한 세션에 무관한 일을 섞으면 어떤 불편이 생기는지 겪어 보고, 세션을 나눴을 때의 차이를 느낍니다.

**🛠 준비**
- 지금 튜터 세션은 그대로 둡니다. 먼저 이 세션 이름을 `튜터_3회차`로 바꿔 두세요. 돌아오기 쉽고, 습관 ② 연습도 됩니다.
- 실습 데이터: 이번엔 짧은 글 요청이라 **① 아래 가상 내용**으로 충분합니다. 내 업무 주제로 바꿔도 되지만 실명·연락처는 넣지 마세요(③ 실제 자료를 쓸 때는 5회차 개인정보 원칙을 먼저).
- 새 세션을 열 때 폴더는 `gea-claude-tutor` 그대로 둡니다.

**👣 단계**
1. **Ctrl+N**(Mac **Cmd+N**)으로 새 세션을 엽니다. 이것이 '섞인 세션'입니다.
2. 아래 세 요청을 **이 한 세션에** 차례로 보냅니다. 답을 받은 뒤 다음 것을 보내세요.

```
미션펀드 가을 선교지 소식지의 첫 인사말을 3문장으로 써줘. 선교사 이름은 '김은혜 선교사(가명)'로 해줘.
```

```
다니엘칼리지 학부모님께 보낼 10월 16일(금) 체험학습 안내문을 5줄로 써줘.
```

```
중학교 과학 교과서의 진화 서술 보완을 요청하는 청원서 제목 후보를 3개 제안해줘.
```

## Part 3: 인수인계 메모 (15분)

### 3.1 인수인계 메모 = 서류철 맨 앞의 한 장

**🧩 비유**

**설명**

| 핵심 칸 | 내용 예 (체험학습 공지) |
|---|---|

**💭 확인 질문**: 네 칸 중 선생님이 평소 인수인계할 때 가장 자주 빠뜨리는 칸은 무엇인가요?

## Part 4: 오래 기억시키기 — CLAUDE.md (15분)

### 4.1 CLAUDE.md = 책상 앞 벽에 붙여 둔 업무 매뉴얼

**🧩 비유**
신입 동료 책상 앞 벽에 붙은 한 장짜리 안내문입니다. "호칭은 '간사님', 공지문은 개조식, 선교사 실명 절대 금지." 동료는 매일 출근하면 이것부터 봅니다.

**설명**
**CLAUDE.md**는 폴더마다 둘 수 있는 업무 매뉴얼 파일입니다. Claude는 그 폴더에서 **새 세션을 시작할 때마다** 이 파일을 먼저 읽습니다. 그래서 같은 부탁을 매번 반복하지 않아도 됩니다. 인수인계 메모가 '업무 하나'의 기억이라면, CLAUDE.md는 '이 폴더의 모든 업무'에 늘 적용되는 기억입니다.

만드는 법은 두 가지입니다.
- **인터뷰 방식(추천)**: "이 폴더용 CLAUDE.md를 만들어줘. 먼저 나를 인터뷰해줘."
- **`/init`**: 파일이 이미 있는 폴더에서 입력하면 Claude가 폴더를 살펴보고 초안을 만들어 줍니다. 초안은 꼭 읽고 고치세요.

| 넣을 것 | 뺄 것 |
|---|---|
| 호칭·문체(예: 존댓말, 개조식) | "잘 써 줘" 같은 뻔한 말 |
| 금지 사항(예: 실명·연락처 쓰지 않기) | 자주 바뀌는 정보(이번 주 일정 등) |
| 폴더 규칙(원본·산출물 위치, 파일 이름 규칙) | 긴 설명, 자료 내용 통째로 |
| 우리 단체만의 약속(용어·형식) | 개인정보(실명·연락처·계좌) |

짧을수록 잘 지켜집니다. 한 줄마다 "이 줄이 없으면 Claude가 실수할까?"를 묻고, 아니면 지우세요. 대화 중에 "이건 기억해둬"라고 하면 Claude가 기억용 파일에 적어 둘 수도 있지만, 꼭 지켜야 할 규칙은 "CLAUDE.md에 추가해줘"라고 분명히 말하는 편이 확실합니다.

**한번 보기**: 이 튜터 폴더에도 CLAUDE.md가 있습니다. 튜터 세션에서 물어보세요.

```
이 튜터 폴더의 CLAUDE.md를 보여주고, 무슨 내용인지 3줄로 설명해줘.
```

**우리 단체 예시** (규칙 한 줄씩)

| 단체 | CLAUDE.md 규칙 예 |
|---|---|
| 미션펀드 | 보안국가 선교사의 실명·국가명·교회명은 쓰지 않는다. 기도제목에는 번호를 붙인다. |
| 교진추 | 교과서 인용은 쪽수와 원문을 글자 그대로 적고, 대조하지 못한 인용은 '미확인'으로 표시한다. 청원 논거는 교진추(창조과학) 관점에서 쓴다. |
| 다니엘칼리지 | 학부모 답변은 존댓말로 쓰고, 확정되지 않은 일정·비용은 약속하지 않고 "담당자 확인 후 안내"로 쓴다. |
| 엘리온에듀학원 | 원본 원고는 `원본/`에 마크다운으로, PPT·Word는 `산출물/`에 저장한다. |
| 다교연 | 법령·세무 내용에는 국가법령정보센터·국세청 출처와 조항을 붙이고, 불확실하면 "세무서 확인 필요"라고 쓴다. |
| SHINE행복한학교 | 영상 대본은 장면·시간·자막 3열 표로 쓰고, 학생 얼굴·실명이 드러나는 장면은 제안하지 않는다. |

**💭 확인 질문**: CLAUDE.md를 방금 고쳤다면, 효과는 지금 세션과 새 세션 중 어디서 확인해야 할까요?

> [!note] 다니엘칼리지 '대니' 설정값(D3)과 같은 원리
> 다니엘칼리지는 학생과 대화할 AI '대니'가 진화론 자료에 치우친 답으로 잘못된 세계관을 심어 줄까 걱정하며, "미리 설정값을 줄 수 있느냐"고 물었습니다. 답은 "줄 수 있다"이고, 그 원리가 오늘 만드는 CLAUDE.md와 같습니다. 대화가 시작될 때마다 AI가 먼저 읽는 안내문에 "창조주 하나님과 성경의 권위를 전제로 답한다", "진화론 질문에는 교과서의 설명과 성경적 관점을 구분해 알려 준다", "모르거나 민감한 질문은 담당 선생님께 연결한다" 같은 규칙을 적어 두는 것입니다. 다만 설정값은 강한 지시일 뿐 100% 보장이 아니므로, 오늘 새 세션으로 효과를 확인하듯 대니도 시험 질문으로 반드시 확인해야 합니다(10회차에 가드레일 테스트 질문을 만듭니다).

### 4.2 실습: 연습 폴더에 CLAUDE.md 만들고 효과 확인하기

**🎯 목표**: 연습 폴더용 CLAUDE.md를 만들고, 새 세션에서 따로 말하지 않아도 규칙이 지켜지는지 확인합니다.

**🛠 준비**
- `튜터_3회차` 세션.
- 실습 데이터 선택: **① 가상의 '우리 단체' 규칙**(기본) 또는 **② 내 단체의 실제 문체·규칙**(개인정보 없이). 어느 쪽이든 실명·연락처는 CLAUDE.md에 넣지 않습니다.

**👣 단계**
1. 튜터 세션에서 요청합니다.

```
실습공간/03회차/우리단체_연습/ 폴더를 만들고, 그 폴더용 CLAUDE.md를 만들어줘. 먼저 나를 인터뷰해서 ① 나를 부르는 호칭 ② 글의 문체 ③ 절대 하지 말 것 2가지 ④ 파일 저장 규칙을 정해줘. 완성본은 10줄 이내로.
```

2. 인터뷰에 답하고, 파일 만들기를 승인합니다. 완성된 내용을 한 번 읽어 보세요.
3. **Ctrl+N**으로 새 세션을 열고, **Select folder**로 `gea-claude-tutor/실습공간/03회차/우리단체_연습` 폴더를 고릅니다.
4. 규칙은 **말하지 않고** 부탁합니다.

```
우리 단체 이번 달 소식지에 들어갈 인사말을 3문장으로 써줘.
```

5. 호칭·문체·금지 사항이 지켜졌는지 봅니다. 그리고 물어봅니다.

```
이 폴더에서 너에게 주어진 규칙이 있어? 있으면 요약해줘.
```

6. (선택, 비교) 새 세션을 하나 더 열어 폴더를 `실습공간/03회차`로 고르고, 4단계와 같은 부탁을 보냅니다. 두 답을 나란히 비교해 보세요.

### 퀴즈 정답과 해설

1. **②** — 책상이 차면 앞부분을 요약해 치우고 계속합니다. 그래서 세부가 빠질 수 있고, 중요한 결정은 파일(인수인계 메모·CLAUDE.md)에 남깁니다. ①③④는 모두 사실이 아닙니다.
2. **X** — 사이드 챗은 본 대화를 읽기만 하고 본 대화에 아무것도 더하지 않으며, 앱에 저장되지 않습니다. 남길 내용은 본 대화로 옮겨야 합니다.
3. **②** — 실패한 시도가 책상에 쌓이면 더 헷갈립니다. 배운 점을 담은 새 지시로 새 세션에서 시작하는 편이 빠릅니다(딸깍 카드 5번). ③은 실패 기록을 요약해 들고 가는 셈이라 효과가 약합니다.
4. **한 일 · 결정 · 남은 일 · 주의사항**. (표현이 조금 달라도 네 내용이 있으면 정답)
5. 예시 정답 — 넣기 좋은 것: 호칭·문체·금지 사항·폴더 규칙 중 하나. 넣으면 안 되는 것: 개인정보, 자주 바뀌는 정보, 뻔한 말, 긴 자료 통째. 이유: CLAUDE.md는 **새 세션을 시작할 때 읽히므로**, 이미 진행 중인 세션에서는 변경 효과를 확인하기 어렵습니다.

소크라테스식으로: 틀리면 바로 정답을 주지 말고 해당 비유(책상·옆자리 동료·인수인계서·벽의 안내문)를 떠올리게 하는 힌트부터 줍니다.

### 안전·개인정보 주의

- **CLAUDE.md에는 개인정보를 적지 않습니다.** 매 세션 읽히고, 4회차 이후 Git·GitHub로 공유될 수 있습니다.
- **인수인계 메모**에도 실명·연락처 대신 가명·역할("담당 선교사 A")을 씁니다. 보안국가 선교사 정보(실명·국가·얼굴·교회명·종교 용어)는 애초에 AI 입력에서 제외합니다(5회차 원칙).
- 사이드 챗은 앱에 저장되지 않을 뿐, 내용은 똑같이 전송·처리됩니다. "저장 안 됨 = 안전"이 아님을 짚어 줍니다.
- 데스크탑 앱은 대화 기록을 내 PC에 남기므로 **공용 PC**에서는 주의합니다.
- 실전 과제에서 실제 업무 폴더를 열 때, 그 안에 개인정보 파일이 있으면 Claude가 읽을 수 있습니다. 개인정보 없는 폴더를 쓰거나 복사본에서 개인정보 파일을 빼고 진행하게 합니다.
- `내_학습기록/`과 `실습공간/`은 튜터 업데이트(git) 대상에서 제외되어 있어, 튜터를 업데이트해도 기록이 지워지지 않습니다.

### 자가학습 첫 회차 운영 팁 (강사 동석 없음)

- 이 회차부터 강사가 옆에 없습니다. 시작할 때 '혼자 하실 때의 요령' 상자를 짧게 짚고, 명령어는 **다음 · 쉽게 · 도움 · 저장** 네 개만 먼저 기억하게 합니다.

- 회차를 마칠 때 `/handoff`로 오늘 학습의 인수인계 메모를 남기자고 제안합니다. 오늘 배운 것을 그대로 쓰는 마무리입니다.
