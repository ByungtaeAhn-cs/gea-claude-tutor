## Part 1: RCIF 위임 브리핑 — 네 칸으로 일 맡기기

### 1.1 네 칸 브리핑 = 휴가 전 업무 메모

🧩 **비유**: 휴가를 떠나기 전, 대신 일해 줄 새 간사에게 업무 메모를 남긴다고 생각해 보세요. "누구 입장에서(역할), 지금 무슨 상황인지(맥락), 무엇을 해 달라는지(지시), 어떤 모양으로 내 달라는지(형식)"가 적혀 있으면 새 간사도 헤매지 않습니다.

**설명**: Anthropic 공식 문서도 Claude를 '우리 업무 방식을 아직 모르는 똑똑한 신입 직원'처럼 대하라고 안내합니다. 이 네 칸을 채워 주는 만큼 결과가 좋아집니다. 네 칸의 영어 머리글자를 따서 **RCIF**라고 부릅니다.

| 칸 | 뜻 | 이렇게 말해요 | 우리 단체 예 |
|---|---|---|---|
| **R** 역할(Role) | 어떤 전문가처럼 일할지 | "너는 ~야" | "너는 선교 단체 후원자 소식지 편집자야" |
| **C** 맥락(Context) | 누구에게, 왜, 어떤 재료로 | "상황은 이래" | "독자는 60대 후원자가 많고, 첨부한 선교사 편지가 재료야" |
| **I** 지시(Instruction) | 정확히 무엇을, 얼마나 | "~해줘" + 숫자 | "근황 300자와 기도제목 3줄을 써줘" |
| **F** 형식(Format) | 어떤 모양으로 | "~ 모양으로" | "제목-소제목-본문 순서, 워드에 붙일 평문으로" |

**우리 단체 예**: 네 칸 중 결과를 가장 크게 바꾸는 칸은 대개 **맥락(C)** 입니다. 이유도 함께 말해 주세요. "학부모님들이 카톡 미리보기로 첫 두 줄만 보셔서"라고 이유를 알려 주면, Claude가 나머지 문장도 알아서 거기에 맞춥니다. 내 부탁을 옆자리 동료에게 보여 줬을 때 동료가 헷갈려하면 AI도 헷갈립니다.

💭 **확인 질문**: 지난주에 동료에게 맡긴 일 하나를 떠올려 보세요. 네 칸 중 말하지 않고 넘어간 칸은 무엇이었나요?

### 1.2 Bad / Good 세 쌍

**① 소식지 글 (다교연)** — ❌ `이번 달 소식지 써줘.`
```
[역할] 너는 기독교 교육단체 연합의 소식지 편집자야.
[맥락] 다음세대교육연합 10월 소식지고, 독자는 후원자와 회원 단체 실무자야. 첨부한 회원 단체 3곳의 활동 메모가 재료야.
[지시] 단체별로 꼭지 1개씩, 각 300자 안팎으로 쓰고 마지막에 기도제목 3줄을 붙여줘.
[형식] 제목-소제목-본문 순서. 워드에 바로 붙일 수 있는 평문으로.
```

**② 학부모 공지 (다니엘칼리지)** — ❌ `공지 짧게 써줘.`
```
[역할] 너는 다니엘칼리지에서 학부모 소통을 맡은 간사야.
[맥락] 10월 튜터링이 화요일 저녁 7시에서 목요일 저녁 7시로 바뀌었어(연습용 가상 일정). 학부모님들은 카톡 미리보기로 첫 두 줄만 보고 넘기시는 경우가 많아.
[지시] 변경 안내 공지를 존댓말 5문장 이내로 써줘. 첫 줄에 바뀐 요일·시간과 학부모님이 하실 일을 모두 넣어줘. 어려운 용어는 괄호 안에 쉬운 말로 풀어줘.
[형식] 카톡에 바로 붙일 수 있는 평문. 마지막 줄은 [문의처]라고만 적어 둬.
```

**③ 청원서 요약 (교진추)** — ❌ `이 청원서 요약해줘.`
```
[역할] 너는 교과서 개정 청원 활동을 돕는 정책 보좌관이야.
[맥락] 교과서진화론개정추진회가 교육청 담당자를 만나기 전에 건넬 요약본이야. 담당자는 5분 안에 읽어야 해. 근거는 첨부한 청원서 PDF뿐이야.
[지시] 청원서의 핵심 요청 3가지를 뽑고, 요청마다 근거 문장을 쪽수와 함께 원문 그대로 옮겨줘. 청원서에 없는 내용은 보태지 말고, 찾지 못하면 '원문에 없음'이라고 써줘.
[형식] A4 1쪽 분량의 표: 요청 | 근거 요지 | 원문 인용(쪽)
```
→ 세 쌍 모두 **맥락**(누구에게, 무엇을 재료로)이 생기면서 결과가 달라집니다. ③처럼 "원문 그대로, 쪽수와 함께"를 넣으면 청원서의 신뢰도를 지키는 요약이 됩니다.

### 1.3 네 칸에 더하는 세 가지 요령

| 요령 | 이렇게 말해요 | 우리 단체 예 |
|---|---|---|
| **견본 보여주기**(few-shot: 예시 몇 개로 감을 잡게 하기) | "아래 예시 3개의 길이·말투·구성만 따라 하고, 내용은 베끼지 마." | 반응이 좋았던 지난 소식지 꼭지 3개 붙이기 (미션펀드·다교연) |
| **단계로 나누기** | "3단계로 하자. 1단계만 하고 멈춰서 내 확인을 기다려." | 청원서: 쟁점 서술 원문 목록 → 근거 표 → 초안 (교진추) |
| **반복해서 다듬기** | "구성은 좋아. 세 가지만 고쳐줘: ① 분량 ② 말투 ③ 마지막 문단." | 활동지 난이도·분량 맞추기 (엘리온) |

> 💡 두 번 고쳐도 원하는 결과가 안 나오면, 새 대화에서 지금까지 알게 된 점을 넣어 처음부터 다시 부탁하는 편이 빠릅니다. (3회차에서 자세히)

### 1.4 실습: "이메일 써줘"를 네 칸으로 고치기

🎯 **목표**: 한 줄짜리 부탁을 RCIF로 고쳐 보고, 결과가 어떻게 달라지는지 눈으로 확인한다.

🛠 **준비**
- 실습 데이터 선택: 이 실습은 파일이 필요 없습니다. 실제 업무 메일을 소재로 쓰려면 받는 사람 실명·연락처는 빼고 "회원 단체 담당자"처럼 적습니다.

👣 **단계**

1. 먼저 한 줄 그대로 입력합니다.
   ```
   이메일 써줘
   ```
2. 결과를 봅니다. 누구에게 무슨 메일인지 모르니 두루뭉술한 메일이 나오거나 질문이 돌아옵니다.
3. 아래 예시를 참고해 **선생님 업무**로 네 칸을 채워 입력합니다. (예시를 그대로 넣어 봐도 됩니다.)
   ```
   [역할] 너는 다음세대교육연합 사무국 간사야. 회원 단체들과 오래 일해서 정중하지만 간결한 메일을 잘 써.
   [맥락] 10월 월간 소식지를 만들려고 회원 단체 담당자들에게 활동 자료를 받아야 해. 담당자들은 바빠서 메일을 휴대폰으로 훑어봐.
   [지시] 자료 요청 메일을 써줘. 보낼 것(활동 사진 2~3장, 300자 안팎 소개글)과 마감(10월 15일)을 분명히 적고, 마감을 제목에도 넣어줘.
   [형식] 제목 1줄 + 본문 8줄 이내. 첫 두 줄에 '무엇을, 언제까지'가 보이게. 마지막 줄은 [문의처]라고만 적어 둬.
   ```
4. 두 결과를 비교하고, 튜터에게 평가를 받습니다.
   ```
   내가 쓴 네 칸 프롬프트에서 가장 약한 칸 하나만 알려주고, 그 칸을 보강할 질문을 2개 해줘.
   ```
5. 저장합니다.
   ```
   처음 부탁과 고친 부탁, 두 결과의 차이를 한 문단으로 정리해서 실습공간/02회차/이메일_비교.md로 저장해줘.
   ```

✅ **이렇게 되면 성공**: 네 칸이 모두 채워져 있고, 받는 사람·목적·마감(날짜)이 들어 있으며, 두 결과의 차이를 한 문장으로 말할 수 있습니다.

🆘 **막히면**: 칸마다 한 줄이면 충분합니다. 무엇을 쓸지 모르겠으면 **예시 더**라고 입력하세요. 형식 칸이 막히면 "제목 1줄 + 본문 8줄 이내"처럼 숫자만 적어도 됩니다.

## Part 2: 딸깍 메타프롬프트 7종

### 2.1 메타프롬프트 = 신입에게 주는 '일하는 방식' 허락

🧩 **비유**: 일 잘하는 신입은 일을 받자마자 쓰기 시작하지 않습니다. 자료철을 먼저 훑고, 궁금한 걸 여쭤보고, 계획을 보여 드린 뒤 시작합니다. 메타프롬프트는 신입에게 **"그렇게 일해도 된다"고 허락해 주는 한 줄**입니다.

**설명**: **메타프롬프트**(일의 내용이 아니라 '일하는 방식'을 정해 주는 지시)는 어떤 일에든 붙여 쓸 수 있습니다. 외워 두면 '딸깍' 한 번에 붙이듯 쓸 수 있어서 **딸깍 프롬프트**라고 부릅니다. RCIF 네 칸을 다 채우기 어려울 때는 ①번 한 줄로 **Claude가 빈칸을 질문해서 채우게** 하면 됩니다.

**우리 단체 예**: "학부모 안내문 써줘"만 보내면 Claude는 학년과 날짜를 짐작해서 씁니다. ①을 붙이면 "어느 학년 학부모님께 보내나요?", "바뀐 일정은 언제인가요?"부터 묻습니다.

### 2.2 7종과 왜 통하는지

**① 먼저 조사하고, 애매한 건 인터뷰**
```
○○ 하고 싶어. 먼저 조사하고 시작하자. 애매한 건 나를 인터뷰해서 정해줘.
```
- **하는 일**: 관련 자료를 먼저 살펴본 뒤, 빠진 정보를 선생님에게 질문해서 채우고 시작합니다.
- **왜 통하나**: 신입이 "이건 누구에게 가는 문서인가요?"라고 여쭤보면 헛수고가 줄지요. AI는 모르는 칸을 **추측**으로 채우는데, 이 한 줄이 추측을 **질문**으로 바꿉니다. Claude Code 공식 모범 사례도 '먼저 살펴보고, 계획하고, 그다음 실행하기'와 'Claude가 나를 인터뷰하게 하기'를 권합니다.

**② 계획부터**
```
바로 하지 말고 계획부터 보여줘.
```
- **하는 일**: 파일을 만들거나 고치기 전에, 무엇을 어떤 순서로 할지 먼저 보여 줍니다.
- **왜 통하나**: 도배하기 전에 벽지 시안부터 보는 것과 같습니다. 잘못된 방향은 계획 단계에서 고치는 게 가장 쌉니다. 더 확실히 하려면 전송 버튼 옆 **권한 모드 선택기**에서 **Plan**(파일은 안 고치고 계획만 제안, 이 세션에만 적용)을 고르세요. 말로 부탁하는 데서 그치지 않고, 아예 '계획서만 쓰는 모드'로 바꾸는 셈입니다.

**③ 초등학생도 알게**
```
이 과정을 초등학생도 알게(eli5) 설명해줘.
```
- **하는 일**: 방금 한 일이나 어려운 개념을 아주 쉬운 말로 풀어 줍니다.
- **왜 통하나**: 전문가의 설명을 통역사가 쉬운 말로 옮겨 주는 것과 같습니다. 선생님이 이해해야 **승인해도 되는지 판단**할 수 있습니다. eli5는 영어권 관용어 'Explain Like I'm 5(다섯 살 아이에게 설명하듯)'의 줄임말이며, 특별한 기능 이름은 아닙니다.

**④ 어디쯤이야?**
```
지금 전체 과정 중 어디쯤이야?
```
- **하는 일**: 긴 작업에서 끝난 단계, 지금 단계, 남은 단계를 알려 줍니다.
- **왜 통하나**: 내비게이션의 '남은 거리' 표시와 같습니다. 여러 단계로 오래 일하다 보면 사람도 AI도 길을 잃기 쉬운데, 이 한 줄로 서로 위치를 맞춥니다.

**⑤ 스스로 검토하고 표시**
```
끝나면 스스로 검토하고 확실/불확실/추측을 표시해줘.
```
- **하는 일**: 결과를 다시 훑어보고, 확인된 것과 짐작한 것을 나눠 표시합니다.
- **왜 통하나**: 보고서를 올리기 전에 "확인한 것 / 확인 못 한 것"을 표시하는 신입은 믿을 수 있지요. Anthropic 공식 문서도 불확실하면 그렇다고 말하도록 **허락**하고, 끝내기 전에 기준과 대조하게 하라고 권합니다. 다만 AI의 자기 검토는 **1차 거름망**일 뿐입니다(Part 3).

**⑥ 이미 있는 도구부터**
```
이 일을 해주는 검증된 도구나 플러그인이 이미 있는지 먼저 찾아줘.
```
- **하는 일**: 새로 만들기 전에, 믿을 만한 기존 도구가 있는지 찾아봅니다.
- **왜 통하나**: 서식을 새로 만들기 전에 공유 폴더에 좋은 양식이 이미 있는지 찾아보는 것과 같습니다. "바퀴를 다시 만들지 말자"는 뜻이고, 찾는 법과 설치 전 안전 점검은 8회차에서 배웁니다.

**⑦ 인수인계 메모**
```
지금까지 한 일을 인수인계 메모로 정리해줘.
```
- **하는 일**: 한 일, 정한 것, 남은 일, 주의사항을 메모로 남깁니다.
- **왜 통하나**: 교대 근무자가 인수인계서를 남기면 다음 사람이 바로 이어서 일합니다. AI도 새 대화를 열면 앞의 내용을 모르기 때문에 메모가 다리가 됩니다. 3회차의 핵심 도구입니다.

💭 **확인 질문**: 7종 중 선생님 업무에 가장 먼저 붙여 보고 싶은 한 줄은 무엇이고, 어떤 일에 쓰고 싶으신가요?

### 2.3 실습: Claude에게 인터뷰 받아 보기

🎯 **목표**: 내 업무 하나에 ①을 붙여 보고, Claude가 보기(선택지)를 단 질문으로 나를 인터뷰하는 경험을 한다.

## Part 3: 할루시네이션 기초 — 그럴듯한 거짓 가려내기

### 3.1 AI는 왜 그럴듯하게 틀릴까?

🧩 **비유**: 휴대폰 자판의 자동완성을 떠올려 보세요. "감사합니다" 다음에 올 말을 추천해 주지요. Claude는 이 자동완성을 엄청나게 잘하는 신입입니다. 문장을 '다음에 올 가장 그럴듯한 말'로 이어 붙여 만들기 때문에, **모르는 것도 그럴듯하게 이어 붙일 수** 있습니다.

**설명**: 이렇게 사실이 아닌 내용을 사실처럼 말하는 것을 **할루시네이션**(환각: AI가 그럴듯한 거짓을 만들어 내는 현상)이라고 합니다. 논문 제목·저자·연도, 통계 숫자, 법 조항 번호, 날짜, 쪽수, 성경 장절처럼 **정확한 값**에서 특히 잘 생깁니다. 말투가 자신 있다고 사실인 것은 아닙니다.

**우리 단체 예**: 청원서에 존재하지 않는 논문이 한 편만 섞여도 청원서 전체의 신뢰가 흔들립니다(교진추 T2). 공익법인 신청이나 세무 질문에서 조항 번호 하나가 틀리면 서류를 다시 준비해야 할 수 있습니다(다교연 G1, 미션펀드 M5).

💭 **확인 질문**: 선생님 업무에서 AI가 틀리면 가장 곤란한 '정확한 값'은 무엇인가요?

### 3.2 줄이는 습관 두 가지 + 3단계 검증

**습관 1 — 모른다고 해도 된다고 허락하기** (Anthropic 공식 문서가 할루시네이션을 줄이는 방법으로 가장 먼저 소개하는 기법)
```
모르면 모른다고 해도 돼. 추측한 부분은 [추측]이라고 표시해.
```
**습관 2 — 확실/불확실/추측 표시받기** (메타프롬프트 ⑤)

Anthropic 문서는 이런 기법이 할루시네이션을 크게 줄이지만 **완전히 없애지는 못한다**고 분명히 적어 둡니다. 그래서 중요한 내용은 사람이 확인하는 3단계를 거칩니다.

| 단계 | 하는 일 | 우리 단체 예 |
|---|---|---|
| 1. 출처 요청 | "출처(문서 이름과 쪽, 또는 웹 주소)를 붙여줘." 출처를 못 대면 의심합니다 | 공익법인 요건을 들으면 "어느 법 몇 조야?" (G1) |
| 2. 교차 확인 | 서로 다른 곳 2곳 이상에서 **직접** 확인합니다 | 법령은 국가법령정보센터, 논문은 RISS·KCI, 교과서 인용은 PDF 원문의 해당 쪽 |
| 3. 사람 검토 | 중요한 결정은 담당자·전문가가 확인합니다 | 세무는 세무사(M5), 학부모 안내의 금액·날짜는 담당 간사 |

> 🔎 **Claude Code는 웹 검색으로 출처를 붙일 수 있습니다.** 그래도 링크가 틀렸거나, 링크 내용이 AI의 설명과 다를 수 있습니다. 링크는 **직접 열어** 확인합니다.

### 3.3 실습: 논문 5편, 진짜일까?

🎯 **목표**: AI가 알려 준 인용을 직접 찾아보고, 기억만으로 답할 때와 웹 검색으로 답할 때를 비교한다.

🛠 **준비**
- 인터넷 브라우저와 논문 검색 사이트: RISS(https://www.riss.kr), KCI(https://www.kci.go.kr), Google Scholar(https://scholar.google.com)
- 실습 데이터 선택: 이 실습은 파일이 필요 없습니다.

👣 **단계**

1. 주제를 고릅니다. 기본은 '기독교 대안학교 교육'이고, 단체 주제로 바꿔도 됩니다. (교진추: 중학교 과학 교과서의 진화 단원 서술 / 미션펀드: 선교사 멤버케어 / 다니엘: 학부모와 교사의 소통 / 엘리온: 기독교 세계관 교육과정 / SHINE: 학교 홍보 영상 / 다교연: 다음세대 신앙 교육)
2. 먼저 기억만으로 답하게 합니다. (강사님이 화면으로 먼저 보여 주실 수 있습니다.)
   ```
   인터넷 검색은 하지 말고 네가 알고 있는 것만으로 답해줘. 기독교 대안학교 교육에 관한 한국 논문 5편을 저자·발표 연도·학술지 이름과 함께 인용해줘.
   ```
3. 5편 중 3편을 골라 RISS나 KCI에서 제목으로 검색하고, 아래 표에 적습니다.
4. 이번에는 허락 문장과 웹 검색을 함께 씁니다. 웹 검색을 해도 되는지 물으면 승인합니다.
   ```
   이번에는 웹 검색으로 실제 논문을 찾아서 5편을 다시 알려줘. 논문마다 확인한 웹 주소를 붙여줘. 모르면 모른다고 해도 돼. 끝나면 스스로 검토하고 확실/불확실/추측을 표시해줘.
   ```
5. 링크 2개를 직접 열어 제목·저자·연도가 맞는지 봅니다.
6. 확인 결과를 말로 불러 주고 저장을 부탁합니다.
   ```
   내가 확인한 결과를 불러 줄게. 아래 표 모양으로 실습공간/02회차/검증기록.md에 저장해줘.
   ```

| # | AI가 준 내용 | 어디서 확인했나 | 결과 (✅ 맞음 / ❌ 없음·다름 / ❓ 확인 불가) |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

✅ **이렇게 되면 성공**: 3건 이상을 **직접** 확인해 표에 적었고, 기억만으로 답할 때와 웹 검색으로 답할 때의 차이를 한 문장으로 말할 수 있습니다.

🆘 **막히면**
- 검색이 안 되면 제목 일부나 저자 이름으로 다시 찾습니다. 그래도 없으면 ❌ 또는 ❓로 적으면 됩니다. **없다는 것을 확인한 것도 성공**입니다.
- 5편이 모두 맞게 나왔다면 그것도 좋은 결과입니다. 선생님이 **확인했기 때문에** 믿을 수 있게 된 것입니다. 결과는 할 때마다 다를 수 있습니다.
- Claude가 "정확하지 않을 수 있습니다"라며 조심스럽게 답하거나 인용을 사양하면, 그것이 바로 우리가 바라는 태도입니다.

## Part 4: 관통 프로젝트 고르기

### 4.1 관통 프로젝트 = 수습 기간의 첫 담당 업무

🧩 **비유**: 신입의 수습 기간 동안 함께 끝까지 해낼 **첫 담당 업무** 하나를 정하는 것입니다. 배운 기술을 그 일 하나에 계속 적용하면, 10회차가 끝날 때 실제로 돌아가는 결과물이 남습니다.

**설명**: 관통 프로젝트는 5~10회차 실전 과제에서 단계별로 키워 10회차에 완성과 자동화까지 가는 **내 업무 하나**입니다. 고를 때 네 가지를 봅니다.

| 기준 | 스스로 물어볼 질문 |
|---|---|
| 반복 | 매주·매달·매 분기 되풀이되는 일인가? |
| 시간 | 지금 시간이 많이 드는 일인가? |
| 확인 | 잘 됐는지 확인할 수 있는가? (건수, 마감, 받는 분 반응 등) |
| 연습 가능 | 개인정보를 빼거나 가상 데이터로 연습할 수 있는가? |

**우리 단체 예**: 너무 큰 일은 **한 조각**만 떼어 냅니다. 케냐 교과서 제작 전체(G10) 대신 "스캔 1쪽 → 자료실 한 장", 학부모 응대 챗봇 전체(D1) 대신 "자주 묻는 질문 20개의 답변 초안과 검수 규칙"처럼요.

💭 **확인 질문**: 1회차에 말씀하신 '가장 해결하고 싶은 일'은 네 기준 중 몇 개에 해당하나요?

### 4.2 우리 단체 사전질문 목록

튜터는 선생님 프로필의 소속 단체를 보고 해당 목록을 먼저 보여 드립니다. 강의 전에 단체에서 보내 주신 질문을 쉬운 말로 바꾼 것이고, 오른쪽 칸은 그 일을 주로 다루는 회차입니다. 다른 단체 목록에서 골라도 됩니다.

**다음세대교육연합(다교연)**

| 코드 | 쉬운 말로 | 주로 다루는 회차 |
|---|---|---|
| G1 | 공익법인(지정기부금단체) 신청 서류 준비와 최신 법령 확인 | 10 |

### 4.3 실습: 프로젝트 카드 만들기

🎯 **목표**: 프로젝트 하나를 고르고, Claude의 인터뷰를 거쳐 프로젝트 카드를 `내_학습기록/내_프로젝트.md`에 저장한다.

🛠 **준비**
- 4.2 목록과, 1회차에 말한 '가장 해결하고 싶은 일'
- 실습 데이터 선택: 카드에는 개인정보의 **종류**만 적습니다(예: "후원자 이름·연락처 있음"). 실제 이름·번호·금액은 적지 않습니다.

👣 **단계**

1. 목록에서 1개를 고르거나 내 업무를 말합니다. 고민되면 이렇게 부탁합니다.
   ```
   내 프로필을 보고, 반복·시간·확인·연습 가능 네 기준으로 우리 단체 질문 중 두 개를 추천하고 비교해줘.
   ```
2. 메타프롬프트 ①로 인터뷰를 시작합니다. 대괄호 안만 내가 고른 것으로 바꿉니다.
   ```
   관통 프로젝트로 [G2 후원 엑셀 자동 점검]을 하고 싶어. 먼저 조사하고 시작하자. 애매한 건 나를 인터뷰해서 정해줘.
   인터뷰가 끝나면 2회차 교재의 프로젝트 카드 양식을 채워서 내_학습기록/내_프로젝트.md에 저장해줘.
   ```
3. 인터뷰에 답합니다. 카드 여섯 칸(목표, 지금 방식, 걸리는 시간, 원하는 결과물, 개인정보 포함 여부, 성공 기준)을 채우는 질문이 옵니다.
4. 저장된 카드를 읽고 고칠 곳을 말합니다. 예: `성공 기준을 숫자로 확인할 수 있게 바꿔줘.`
5. 마지막으로 확인합니다.
   ```
   내 프로젝트 카드를 초등학생도 알게 세 줄로 요약해줘.
   ```


### 수준별 설명 가이드
- 🌱 **입문**(폰 AI만 써 봄): RCIF는 "업무 메모 네 칸"으로만 설명하고 영어 약자는 뒤로 미룹니다. 1.4 실습은 예시를 복사해 한두 단어만 바꾸게 합니다. 메타프롬프트는 7종을 외우게 하지 말고 ①②⑤ 세 줄만 카드로 챙기게 합니다. 할루시네이션은 "자동완성" 비유와 "링크는 열어 본다" 규칙 하나만. 인터뷰할 때는 보기(선택지)를 달아 한 번에 한 질문씩.
- 🌿 **기초**(PC로 AI·엑셀 업무 익숙): 1.3 세 요령까지 다룹니다. 권한 모드 선택기에서 **Plan**으로 직접 바꿔 ②를 체험하게 합니다. 3단계 검증을 자기 업무(엑셀 숫자, 공문 날짜)에 어떻게 적용할지 스스로 말하게 합니다. 성공 기준은 반드시 숫자로.
- 🌳 **중급**(자동화·코딩 경험 있음): Anthropic 공식 문서의 할루시네이션 줄이기 기법 이름을 소개해도 됩니다 — 모른다고 말하게 허락, 답하기 전에 근거 문장을 글자 그대로 먼저 인용, 쓴 뒤 문장마다 근거를 찾고 못 찾으면 철회, 결론 전에 추론을 단계별로 보여 주기(**Chain-of-thought verification**), 같은 질문을 여러 번 돌려 비교(Best-of-N). 자료를 `<자료>…</자료>` 같은 태그로 구분하는 요령도 좋습니다. 프로젝트 카드는 10회차 설계 6요소(목표·단계·근거·검수자·승인·기록)를 염두에 두고 쓰게 합니다.

> **용어 구분(정확히)**: Anthropic 할루시네이션 문서에 나오는 이름은 **Chain-of-thought verification**(단계별 추론을 보여 주며 검증)입니다. **Chain-of-Verification(CoVe)** 은 Meta AI 연구진의 2023년 논문 기법(초안 → 검증 질문 계획 → 검증 질문에 **독립적으로** 답하기 → 최종 답)이며 Anthropic 문서의 기법이 아닙니다. 초보자용으로는 "초안에서 확인할 질문 5개 만들기 → **새 대화**에 질문만 붙여 답 받기 → 비교"로 풀어 주고, 10회차(작성자·검수자 분리)로 연결합니다. 원 자료의 '단계별 사고(Chain of Thought)'는 일을 단계로 나눠 시키는 요령이므로 검증 기법 이름과 섞지 않습니다.

### 퀴즈 정답과 해설
1. **② 맥락**. 역할(편집자)·지시(꼭지 3개, 300자)·형식(제목-본문)은 있지만, 어느 단체 소식지인지, 독자가 누구인지, 무엇을 재료로 쓰는지가 없습니다.
2. **X**. 링크 자체가 틀렸거나 링크 내용이 AI 설명과 다를 수 있습니다. 링크를 직접 열어 제목·저자·연도(또는 조항·날짜)를 대조합니다.
3. **③ Plan**. 파일은 고치지 않고 계획만 제안하며 이 세션에만 적용됩니다. Bypass permissions는 이 과정에서 쓰지 않습니다.
4. 예시 답: "AI는 모르는 정보를 추측으로 채우는데, 이 문장을 붙이면 추측 대신 나에게 질문해서 채우기 때문에 내 의도에 맞는 결과가 나온다." '추측 대신 질문' 또는 '빠진 맥락을 채운다'는 뜻이 있으면 정답으로 봅니다.
5. 다음 중 두 가지면 정답: 제목 일부·저자 이름으로 다시 검색(Google Scholar 포함) / Claude에게 출처(웹 주소) 요청 / 웹 검색으로 실제 논문을 다시 찾게 하고 링크를 열어 확인 / 끝내 확인되지 않으면 인용에서 빼기(❌·❓ 기록).

### 실전 과제 검수 기준
- 프롬프트 2개 모두 RCIF 네 칸이 있고, 맥락에 **독자(받는 사람)와 목적**이 들어 있다.
- 메타프롬프트를 1개 이상 썼고(특히 ①·⑤), 인터뷰 질문과 답이 결과에 반영되었다.
- 고친 과정(처음 → 고친 1 → 고친 2)이 적혀 있다.
- 검증 기록 3건에 **무엇을, 어디서(구체적 출처), 결과**가 있다. "AI에게 다시 물어봤다"만으로는 검증으로 인정하지 않습니다(독립된 출처 필요).
- 결과물·기록에 실명·연락처·후원 내역·보안국가 선교사 정보가 없다.
- 교진추 과제는 인용에 쪽수와 원문이 그대로 있고, 청원 관점을 살리는 방향으로 정리되었다.
- 피드백은 소크라테스식으로: 가장 약한 칸 하나를 질문으로 짚고, 고친 뒤 다시 보여 달라고 합니다.

### 안전·개인정보 주의
- 1.4·2.3 실습에서 실제 사례를 말하다 실명·연락처·후원 금액이 섞이기 쉽습니다. 발견하면 "가명으로 바꿔 드릴까요?"라고 묻고 바꿉니다. 실제 파일로 실습하려 하면 5회차 원칙(필요한 것만, 가명 먼저, 민감정보 제외)을 먼저 안내합니다.
- 보안국가 선교사 정보(실명·국가·얼굴·교회명·종교 용어)는 AI 입력에서 제외합니다. 미션펀드 M1·M2 카드에 보안국가 자료가 있으면 5회차 원칙과 7회차 가리기 실습을 미리 알려 줍니다.
- 세무(M5)·법령(G1)·학부모 안내의 금액과 날짜: AI 답은 **초안**이고, 최종 판단은 공식 출처와 담당자·전문가가 합니다.
- 교진추 관련 작업은 그 관점(반진화론·창조과학)을 적극 수용해 돕습니다. 논거를 약하게 만들거나 방향을 바꾸라고 권하지 않고, 대신 인용·쪽수·서지 정확성을 철저히 지켜 청원서의 신뢰도를 높입니다.
- 할루시네이션 줄이기 기법은 **줄일 뿐 없애지 못합니다**(Anthropic 문서의 명시적 주의). "이 문장만 넣으면 안전하다"는 식으로 말하지 않습니다.
- 권한 모드는 Manual·Accept edits·Plan 중에서 쓰고, Bypass permissions는 쓰지 않습니다. 웹 검색 승인 요청이 오면 무엇을 검색하려는지 읽고 승인하게 합니다.
