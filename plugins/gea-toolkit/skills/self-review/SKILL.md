# 스스로 검토하기 (확실/불확실/추측 표시)

검토 대상: $ARGUMENTS
(비어 있으면 이번 세션에서 가장 최근에 만든 결과물을 검토합니다.)

결과물을 **고치기 전에 먼저 보고**합니다. 수정은 사용자가 승인한 뒤에 합니다.

## 점검 순서

1. **요구사항 대조**: 처음 요청(목적·대상·형식·분량·마감)을 다시 적고, 항목마다 충족/부분/미충족을 표시합니다.
2. **사실 주장 목록**: 결과물 속 사실·숫자·날짜·인용·출처를 뽑아 아래처럼 나눕니다.
   - ✅ 확실: 원자료나 공식 출처로 확인됨(근거 위치를 적음)
   - ⚠️ 불확실: 그럴듯하지만 확인하지 못함(무엇으로 확인하면 되는지 적음)
   - ❓ 추측: 근거 없이 채운 것(삭제하거나 사람이 확인해야 함)
3. **숫자 검산**: 합계·건수·비율은 암산하지 않고 코드로 다시 계산해 결과물과 비교합니다.
4. **인용 대조**: 인용문은 원문과 글자 그대로 같은지, 쪽수·장절이 맞는지 대조합니다.
5. **누락과 모순**: 빠진 항목, 앞뒤가 안 맞는 부분을 찾습니다.
6. **개인정보·보안**: 실명·연락처·주민번호·계좌·보안국가 선교사 정보(국가명·교회명·종교 용어·얼굴·위치)가 남았는지 봅니다.

## 보고 형식

```markdown
## 스스로 검토 결과
**한 줄 판정**: 그대로 사용 가능 / 수정 후 사용 / 다시 작성 필요

| 항목 | 결과 | 근거·위치 | 제안 |
|------|------|-----------|------|

**확실 N개 · 불확실 N개 · 추측 N개**
**사람이 꼭 확인할 것**: 1~3개
```

마지막에 "제안대로 고칠까요?"라고 묻습니다.
