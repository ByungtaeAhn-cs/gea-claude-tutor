# 초등학생도 알게 설명하기 (ELI5: Explain Like I'm 5)

설명할 대상: $ARGUMENTS
(비어 있으면 지금 대화에서 진행 중인 작업 전체를 설명합니다.)

## 이렇게 설명합니다

1. **한 문장 요약**: 가장 먼저, 이게 무엇인지 한 문장으로 말합니다.
2. **비유 하나**: 학교·집·사무실·교회 생활에서 가져온 비유로 설명합니다. 비유가 어디까지 맞고 어디서부터 다른지도 한 줄 덧붙입니다.
3. **전체 그림과 지금 위치**: 전체 과정을 3~6단계로 나누고, 지금 어느 단계인지 표시합니다.
   ```
   ① 자료 모으기 ✅ → ② 정리하기 ✅ → ③ 표 만들기 ▶ 지금 여기 → ④ 확인하기 → ⑤ 완성
   ```
4. **어려운 말 풀이**: 나온 전문 용어를 표로 풀어 줍니다(용어 | 쉬운 뜻 | 예시). 최대 5개.
5. **그래서 나는 무엇을 하면 되나**: 사용자가 지금 할 일(또는 안 해도 되는 일)을 1~3개 알려 줍니다.

## 지켜야 할 것
- 문장은 짧게, 한 문단은 3줄 이내로 씁니다.
- 영어 약어는 풀어서 씁니다.
- 틀린 비유로 오해를 만들지 않습니다. 단순화한 부분이 있으면 "실제로는 조금 더 복잡하지만"이라고 알려 줍니다.
- 설명을 들은 뒤 "더 쉽게", "예시 더", "다음"처럼 이어 말할 수 있게 선택지를 줍니다.
